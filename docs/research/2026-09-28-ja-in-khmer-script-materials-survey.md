# 既存教材・慣習の調査: 日本語の音をクメール文字で表記している例

調査日: 2026-09-29(環境上の日付)。調査者: 調査エージェント。リポジトリのファイルは編集していない。
方針: 確認できた事実と確認できなかったことを分ける。推測で例を作らない。

## 0. 結論(先に)

1. **体系的で出典のある「日本語→クメール文字」の慣習は、今回の調査では確認できなかった。**
   国際交流基金(JF)プノンペン事務所の公式教材(いろどり クメール語版)は、日本語の音を **ローマ字(Ojigi, Sayonara, Shitsurei Shimasu)で示す**のが基本で、クメール文字のかな転写表は見つからなかった。ただし1箇所だけ、本文中の語にクメール文字の音写が括弧書きで付いている(下記 2-1)。
2. 唯一、かな一覧の全体をクメール文字で書いた表として確認できたのは、**クメール語版 Wikipedia の「ហ៊ីរ៉ាហ្កាណា」「កាតាកាណា」の表**。ただしこれは百科事典記事(編集者不明、出典の注記なし)で、**1つのかなに複数の候補を併記**しており、教材としての単一の規約ではない。
3. 借用語(すし・きもの等)は Wiktionary のクメール語見出し語で確認でき、`ស៊ូស៊ី` `គីម៉ូណូ` など一定の型が見える(下記 3)。長音・促音の書き分けは、ここでも見えない。
4. 以上から、ADR-0010 の「既存教材の慣習をそのまま採る」案を退ける根拠(慣習が単一でない・長短/促音/アクセントを書き分けていない)は、**「見つかった範囲では成り立つ」が、「調べ切れていない」ことが前提**になる。ネイティブ・現地教材の実物確認(特に JF/CJCC/RUPP IFL の紙の教材、送り出し機関の内部教材)は未了。

## 3. 逆方向(クメール語を日本語=カタカナで書く)

- 東京外国語大学 言語モジュール(カンボジア語): 発音記号(IPA)・カタカナ・ローマ字の3つで音を示し、カタカナは「時間が無い緊急用」。「カンボジア語の音は日本語よりも種類が多いので、カタカナではどうしても正確な音を表すことができません」と明記している。また、クメール文字自体を覚えることを勧めている。
  - https://www.coelang.tufs.ac.jp/mt/km/pmod2/
- 学習者の note 記事(伊藤充臣・Nancy 等)にも「カタカナ表記をやめたい。文字が難しいため頼らざるを得なかった」「子音の2系列によって母音の読みが変わる」といった記述がある。色分けの子音表を作る方法などを紹介。
  - https://note.com/nancy_phn/n/n14a96820772a
- 日本語→クメール語の辞書(jp-kh-dict.com)は、クメール文字の音写を出さない(上記)。
- 今回の調査では、クメール語の辞書での日本語の音の音写(たとえばクメール語側の語釈中の日本語のクメール文字表記)の具体例を、ほかに確認できていない。

## 4. 一貫性についての評価(事実と、そこからの見立てを分ける)

**事実として確認できたこと**
- 同じ「ヒラガナ」の語自体が、Wikipedia では `ហ៊ីរ៉ាហ្កាណា`、JF では `ហិរាហ្កាណា` と綴られる(系列変換 ៊ の有無、長母音 ី/短 ិ、ら行の ៉ の有無)。
- Wikipedia の表は、1つのかなに複数の系列(例: か = ខ/ក、が = ហ្ក/ហ្គ/ង៉、ぱ = ផ/ប៉)を併記していて、単一の規約が無い。
- 借用語の綴りも、語ごとに違う書き方(`អុនសេន` の短い ុ と、`គីម៉ូណូ` の長い ូ)が同居している。
- 長音・促音・アクセントの書き分けは、今回見た範囲のどの資料にも確認できなかった。
- JF の公式教材は、日本語の音を**ローマ字**で示している(見た範囲では)。

**見立て(要確認)**
- 「教材ごとに違い、単一の慣習は無い」と言える材料は揃っているが、調べ切れていない(紙の教材、内部教材、アプリの内部表示、YouTube)。
- ADR-0010 の「既存教材の慣習をそのまま採る案を却下する」根拠としては、「調べた範囲では、採れる単一の慣習が見当たらない」までは言える。「慣習が一貫していない」と断言するには、現地の教材(RUPP IFL、CJCC、送り出し機関)の実物確認が要る。

## 5. 設計へのヒント(推測を含む。判断は呼び出し側に)

- ら行に រ を使い、ម/យ/វ にも ៉ を付けて ា が /aː/ になるようにする型(រ៉ា ម៉ា យ៉ា វ៉ា)は Wikipedia のかな表と、借用語(រ៉ាមេន、វ៉ាសាប៊ី、ម៉ានហ្គា)の両方で見える。ADR の「ら行は រ か ល か」の問いに対して、少なくともこの2資料では ល は使われていない。
- が行は、`ហ្គ`(外来語型: Wikipedia の ហ្កា/ហ្គា、借用語の ម៉ានហ្គា、JF の Ojigi の ហ្គី)が3資料で一致。`ង៉` は Wikipedia の併記の一つにとどまる。
- つ は、借用語(ស៊ូណាមិ)では ស៊ូ だけで、ត្ស は使わない。Wikipedia では ត្ស៊ឹ/ត្ស៊ុ と ស៊ឹ/ស៊ុ を併記。ADR が「つ は慣習が無い」としたことと整合する(慣習は無く、選択肢が併存)。
- ふ は ហ៊្វុ/ហ្វុ(Wikipedia)。借用語の見出しに ふ を含む語は今回の8語に無く、未確認。
- ん は末子音 ន ង ម ំ の併記(Wikipedia)。借用語は ន(ម៉ានហ្គា、អុនសេន、រ៉ាមេន)。同化の環境別選択規則は、どの資料にも見つからなかった。
- 長音・促音の書き分けがこれらの資料に無いことは、ADR-0010 決定3の「長短は右肩の長音記号が第一候補」が既存慣習と衝突しない(上書きする既存の規約が見当たらない)ことを示唆するが、これも見つからなかっただけで、無いことの証明ではない。
