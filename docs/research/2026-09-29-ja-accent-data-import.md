# ja-khmer アクセントデータの取り込み結果(ADR-0021 決定6・8)

## 2. データ形式(要点)

語(見出し語+読み)ごとに 1 レコード、型は `accents[]` に全部残す。

- `word`(Wiktionary のページ名)、`kana`(ひらがな。長音は ー ではなく Wiktionary の表記どおり、う・い を含む形。例: おはよう)、`moraCount`。
- `accents[].nucleus`: 下がり目の直前の拍の番号(1 始まり)。**0=平板**、1=頭高、moraCount=尾高、その間=中高。`type` は heiban/atamadaka/nakadaka/odaka。
- `accents[].pattern`: 辞書どおりの H/L 列(平板は L で始まり、1 拍語の平板は "L")。**語頭が重い音節の簡略化(ADR-0021 決定2)は入れていない**(描画側)。
- `accents[].afterPitch`: 無核の 1 拍の助詞が続いたときの助詞の高さ(平板だけ H)。句の合成(決定6)用。
- `accents[].refs`: Wiktionary の `acc_ref` の略号(NHK・DJR・SMK など)。辞典の本文は取り込まない。
- `accents[].verified`: 全件 `false`(確認者は未定)。検証スクリプトは `true` を弾く(確認者が決まってから緩める)。
- `source`: 出典 URL(ページ版の oldid 付き)、revid、取得日。`via`: `ja-see` で別ページを辿った語だけに付く。
- `nonTokyoOmitted`: `acc_loc` つき(東京以外)で取り込まなかった値(例: ありがとう の愛知の 3)。

kana に ー を使わないのは、Wiktionary の読みがそのままで照合・出典との突き合わせが簡単なため。拍数の数え方は `src/lib.mjs`(ゃゅょゎ・小書き母音は直前と合わせて 1 拍。っ・ん・ー・う/い の長音は 1 拍)。

## 3. 結果

- 語彙 143(重複除去後)→ **取れた 136**、取れなかった 7。型の内訳(アクセント数): 平板 51、頭高 41、中高 31、尾高 15(計 138。複数型の語が 2 語)。
- **既知の 23 語(`accent-cluster.mjs` の WIKT)は 23/23 で核の位置が一致**(実測。突き合わせは長音の表記を正規化して機械的に行った)。
- `ja-see`(見出しが別ページへ移る)を 1 段辿って取れた語が 15 語: はじめまして→初めまして、分かる→わかる、おやすみなさい→お休みなさい、こんにちは→今日は、
  こんばんは→今晩は、おいしい→美味しい、かかる→掛かる、なくす→無くす、よろしく→宜しく、別々→別別、預かる→あずかる、まっすぐ→真っ直ぐ、ご飯→御飯、魚→さかな、今日→きょう。
  こんにちは・こんばんは は Wiktionary の読みが「こんにちわ」「こんばんわ」なので、は→わ に読み替えて照合した(データの kana は語彙側の「こんにちは」)。

### 3.1 複数の型を持つ語(全部残した)
- 結構(けっこう): 0 と 1。三(さん): 0 と 1。どちらを使うかは人が決める(旅行フレーズの けっこうです は「結構」の用法で判断が要る。未確認)。
- 東京の型が 1 つでも、東京以外の型が別にある語は `nonTokyoOmitted` に残した(ありがとう の愛知の 3 など)。

### 3.2 取れなかった語(`out/misses.json`)
- ページが無い: お会計、お待ち、どのくらい、行きたい(いずれも接頭辞つき・句・活用形。見出し語にならない)。
- ja-pron が無い/読みが合わない: お水(ja-pron なし。水 は取れている)、使える(ja-pron なし)、買える(読み かえる のページは かう の活用形扱いで別の読みしか無い)。
- 見る は `acc=a|acc_loc={{w|Tokyo dialect|Tokyo}}` と東京を明示した書き方で、東京式として取り込んだ(頭高=1)。`acc_loc` に Tokyo だけを含む値は東京式とみなす実装(Tokyo-… や京都・大阪を含む値は東京以外)。

### 3.3 迷う点・要注意
- **文字の型指定**(`acc=h/a/o/n`): h=平板 a=頭高 o=尾高 は数字に直した。n(中高)は 3 拍語だけ 2 に決まり、それ以外は位置が分からないので取り込まず `unresolved-acc` にする設計(今回の語彙では発生なし)。
- **出典の略号が無い(refs が空)語**が 23 語ある(すみません、おはよう、下さい、お願い、これ、利用、免税、切符、病院、です、だけ、から、まで、地下鉄、遠い、昼食、両替、五、八、はじめまして、
  おやすみなさい、なくす、預かる)。Wiktionary の編集者が辞典を付けずに書いた値で、根拠が弱い。おやすみなさい は `acc_ref` が `<ref>` の注記(日本国語大辞典第2版)で、略号としては取れていない。
- **助詞・です は値が入っているが規則と食い違う可能性がある**: です=1(デ\ス。ADR-0021 決定6 と整合)、から=1、まで=1、だけ=2、はい=1。助詞の核は句の合成の入力になるので、
  から・まで・だけ の値は人が確認するまで使わない方がよい(未確認。ADR-0021 決定6 の「2 拍以上の助詞は人が与える」に従う)。
- **辞書形にした語**: ko-ja の活用形(できます、かかります、されています、ございます、なくしました、分かりません、助けて、話して、見ている、買えます、使えます、予約しています、預かってもらえます)は、
  ADR-0021 Q5 により対象外にして、辞書形(できる、かかる、なくす、分かる、助ける、話す、見る、買える、使える、予約、預かる)を語彙に入れた。活用形の線は出さない。
  ただし ください(下さい)、ありがとう などの定型は語として取れている。
- **語の切り方**: ko-ja の `parts` は「お待ち」「お会計」「ご予約」「ご利用」のように接頭辞を付けたもの。今回は接頭辞なしの 会計・予約・利用 を取り、お会計/お待ち は取れなかった。
  接頭辞つきの型(お+語は 平板化・頭高化などの規則がある)は別途、人が与える必要がある(一般知識、文献未照合)。
- **語彙が本当に旅行者向けか**: 語彙は ko-ja の語(約 60)+ spike の 23 語 + 頻出語 76 語で、駅名・地名・メニューの品目・数詞の大きい数・助数詞つきの数は入っていない(3.4 参照)。

### 3.4 語彙の穴(今後足すべき語)
- **数詞・助数詞**: 一〜十・百・千・万・円 は入れた(1 拍語の平板は L。連続する数字の型は個別に変わる)。〜個、〜人、〜時、〜円 など助数詞つきは規則が別で未対応。二人(ふたり)は取れている。
- **駅名・地名・固有名詞**: 未対応(東京、京都、新宿など。Wiktionary にも型があるものとないものが混じる)。
- **メニュー・食べ物**: ラーメン、寿司、天ぷら、うどん、味噌汁 など。ご飯、肉、魚、野菜 のみ。
- **フレーズ内の副詞・慣用句**: どのくらい、お願いします、いらっしゃいませ(取れた)、お会計(取れず)など。複合語・慣用句の句分けは人が与える(ADR-0021 決定6)。
- **ja-km 側(日本人向けクメール語コース)の語**は今回の語彙に入れていない。ADR-0021 の 48 語(gloss の日本語)と ko-ja の重なりを取る作業が未着手。
- **packages/content の日本語側**は今回は読んでいない(ko-ja の yaml が別セッション編集中のため語彙は yaml の parts から手で抜き出した)。語の追加は `vocab.tsv` に足して fetch を再実行すればよい。

## 4. 確認が要ること(未確認のもの)
- 全件 `verified:false`。**確認者(日本語話者)は未定**(ADR-0021 Q4)。未確認のまま表示に出すか、確認済みだけ出すかも未決。
- Wiktionary の型と NHK 等の辞典との一致は未照合(23 語は Wiktionary 同士の一致であって、独立した辞典との照合ではない)。
- CC BY-SA の継承範囲の法的判断は未確認(決定8)。このファイルだけを分離し、LICENSE-CC-BY-SA.txt に帰属表示を付けた。ページ版の oldid で履歴(執筆者)へ辿れる。
- 取得した値の型名(平板・頭高など)は Wiktionary の acc の意味づけに依存する。1 拍語の平板を "L" にしたのは東京式の一般的な扱い(一般知識、文献未照合)。
