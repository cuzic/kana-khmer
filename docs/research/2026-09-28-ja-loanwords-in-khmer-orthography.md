## 1. 要約

### 1-1. 集めた量と出典の性格

- 日本語由来の語・固有名詞 **197 行**(同じ語の異綴りを別行にしているため、日本語の異なる語・名は 181)を、出典付きで第2節の表に収めた。内訳: 料理・文化 / 一般語・文 / 地名 / 企業・機関 / 人名。
- 出典の大半は **クメール語版 Wikipedia(km-wp)とその記事間の揺れ**、Wikidata の km ラベル、RFA Khmer の記事。英語版 Wiktionary が「日本語からの借用語」として収録するクメール語見出しは **9 語だけ**(ស៊ូស៊ី គីម៉ូណូ ម៉ានហ្គា រ៉ាមេន វ៉ាសាប៊ី អានីមេ អុនសេន ខារ៉ាអូខេ ស៊ូណាមិ。API の categorymembers で確認、「Khmer terms borrowed from / derived from Japanese」)。
- **王立アカデミーなどの公的な日本語音写規則は見つからなかった**(国家クメール語評議会は 2021 年時点で外来語表記の標準化に着手した段階と報じられている: [r_rac])。つまり「確立した慣習」は、編集者・記者ごとの実践の重なりとして観察するしかない。km-wp は個々の編集者の実践であり、話者一般の慣習と同一とは限らない。

### 1-2. 比較的確立している(ほぼ全出典で一致)

1. **子音字の系列の使い分け**。あ・え・お段は a 系子音字、い・う段は o 系子音字を選ぶ。鼻音・流音・半母音は o 系の字に **◌៉**(a 系へ切り替え)を付けて ម៉ា រ៉ា យ៉ា វ៉ា ម៉ូ រ៉ូ យ៉ូ とする。な行は **ណ**(a 系)を な・ね・の に、**ន**(o 系)を に・ぬ に使う(ណា ណូ ណិ / នី នុ)。ស៊ី ស៊ូ、ហ៊ី、ប៊ី ប៊ូ の ◌៊ も同じ理屈(第3節 3-1)。
2. **借用語慣習の子音**: ざ行=ហ្ស、ぱ行=ប៉、ば行=ប/ប៊、だ行=ដ、が行=ហ្គ または ហ្ក(どちらも多数)、ふ=ហ្វ系、ら行=រ(៉)、拗音=子音字+្យ+母音記号(ក្យូ ឃ្យ រ្យ ខ្យ)。フランス語・英語借用語と同じ型で、後述の第4節と一致する。
3. **東京 តូក្យូ**(Wikidata・km-wp 記事名・RFA 2017 が一致。km-wp 全文検索 130 件、តូគីយ៉ូ・តូគ្យូ は 0 件)。**着物 គីម៉ូណូ**(Wiktionary・km-wp・Wikidata が一致)。**寿司 ស៊ូស៊ី**(同)。
4. **長音・促音の扱い**: 長音はほぼ書き分けない(ូ で おう も お も書く)。促音は「同じ字を重ねる/前の音節に ក់ ត់ ប់ を付ける」の2型が併存(3-2 の促音)。

### 1-4. もう一つの重要な観察: クメール文字にならない・英語読みになる

- **ラテン文字のまま**が多い: Sabay(2015)の Suzuki、Thmey Thmey の Daikin、Khmer Times(AKP)の JETRO・「Sho Hideki」、JICA ページ中の Spien Tsubasa。企業名・人名の相当部分は綴り字を音写せずラテンで載る。
- **英字・英語綴りを英語風に読んだ音写**: JICA→ចៃកា(ジャイカ)、NHK→អិនអេចខេ、Nikkei→ណៃគី、Minebea→មីនីប៊ែរ、New Otani→ញ៉ូវអូតានី、Nakatani の Gen→ជេន。これらは日本語の音(ミネベア・にっけい)とずれるので、対応表の根拠にできない。

### 1-5. 未確認・見つからなかったこと(詳細は第5節)

- **挨拶語(ありがとう・こんにちは・すみません)をクメール文字で書いた例**: 見つからなかった。唯一 「សាយ៉ូណារ៉ា / សាយូណារ៉ា」(さよなら)が 1975 年以前のクメール歌謡の題名として確認できたのみ(eLib)。
- **寿司・ラーメン・わさび以外の料理名(天ぷら・うどん・味噌・刺身など)**: km-wp と検索でクメール文字の綴りは見つからず(ラテン綴りも 0 件)。納豆 ណាត់តូ と酒 សាកិ(見出しのみ)は見つかった。
- **企業の公式クメール語サイト**(トヨタ・ホンダ・ヤマハ・三菱・AEON・ダイキン): JS 描画・403・DNS 不達で、公式の綴りは取得できなかった(報道・百科事典の綴りのみ)。
- **Google Maps の店名**: 取得手段がなく未調査。
- **ネイティブによる読みの確認**: なし。km-IPA の結果は Wiktionary のモジュールの機械出力で、話者の実音ではない。
- **ហ្គ の系列**: Wiktionary の km-IPA は ហ្ក=a 系 /ɡaː/、ហ្គ=o 系 /ɡiə/ と読む。英語版 Wikipedia は ហ្គ を [ɡɑː](a 系)とし、o 系は ហ្គ៊ と書く。ADR-0010 の「系列が食い違う」問題の原因は、この 2 つの記述の違いで、今回の実例(ម៉ានហ្គា・ហ្គាំបា・ហ្គោ)は「ហ្គ に ា を付ける」書き方が広く使われていることを示す。実際に話者がどちらで読むかは未確認。


## 2. 語彙表

- **モーラ列の表記**: `.` はモーラ区切り(語の切れ目は空白)、`:` は長音(ー・う・お・い の伸ばし)、`q` は促音、`n` は撥音。人名は 名 姓 の順のものと 姓 名 の順のものが混在するので、モーラも表の綴りの語順に合わせた。
- **出典欄**: `WD`=Wikidata の km ラベル、`Wikt`=英語版 Wiktionary の見出し、`km-wp`=クメール語版 Wikipedia(記事名または本文)、`km-wikt`=クメール語版 Wiktionary、`RFA`=Radio Free Asia Khmer の記事。他は媒体名。リンク先は末尾の参照定義 `[rN]`。
- **備考**の「見出しのみ」は、本文が 403 などで取得できず、検索結果の見出しで確認したもの。「Latin 綴りとの対応から推定」は、同じ記事の Latin 綴りから日本語の音を推定したもの(かな・漢字が記事に無い)。
- 系列や母音記号の読みは第3節の km-IPA 表を参照。

補足:
- a 系 + ិ は /eʔ/、a 系 + ុ は /oʔ/ と読まれる。**実例の「え」を ិ で書く例が多い**(ណិ ហាកុណិ、តិ អ៊ីវ៉ាតិ、អិ អិហ៊ីម៉ិ、ម៉ិ、រិ ស៊ិរិតុកុ)のは、この読みを利用したものと考えられる(推論)。同じ km-wp の中でも េ(យ៉ាស៊ូហ៊ីរ៉ុ ណាកាសូណេ の ね、ហាកុដាតេ の て)と ិ が併存する。
- a 系 + ោ は /ao/ で「お」にならないので、実例に a 系 + ោ は無い。
- **長さ**: 実例は ា ី ូ を長短に関係なく使い(トヨタの ト・ヨ は短いのに តូ・យ៉ូ)、短い音節に ុ ិ を使う例(ហុនដា の ホ、ក្យូតុ の ト)も併存する。ក់ ត់ ប់ ះ を短い開音節の印として使う書き手もいる(km-wp の「ភាសាជប៉ុន」記事に集中: 助詞 は=`វ៉ាក់`、`ហ្គាក់`、`អុស្ស៊ិអិតិម៉ូរ៉ាតតាក់`、`តះ`。km-wikt の 田中=`តាណាកាក់` も同型)。
- **な行**: ណ(a 系)は ណា ណេ/ណិ ណូ(な・ね・の)に、ន(o 系)は នី នុ(に・ぬ)に使われる。រ・ម・យ・វ が ◌៉ で系列を切り替えるのと同じ仕組みの、ន/ណ 版。

### 3-2. 子音・特殊拍ごとの観察

#### が行(g)

- 綴りの型: **ហ្គ**(ម៉ានហ្គា、ហ្គាំបា、ហ្គោ、ហ្គីហ្វឹ 系)/ **ហ្ក**(ណាហ្កាសាគី、ខាហ្កាវ៉ា、យ៉ាម៉ាហ្កាតា、នីហ្កាតា、ខាហ្កុស៊ីម៉ា、នីហុងហ្កុ、Wiktionary の km-IPA 引数 ម៉ាន-ហ្កា)/ **ង៉**(km-wp の仮名表の候補。実例は គិមិង៉ាយ៉ុ)/ **ក(濁らせない)**(ណាកាសាគុី)。
- **同じ km-wp で ហ្ក と ហ្គ が併存**: 長崎 ណាហ្កាសាគី(本文・ខេត្តណាហ្កាសាគី)と ណាហ្គាសាគី(大学記事)、山形 យ៉ាម៉ាហ្កាតា(県)と យ៉ាម៉ាហ្គាតា(大学)、鹿児島 ខាហ្កុស៊ីម៉ា(県)と ខាហ្គុស៊ីម៉ា(大学)。km-wp 全文検索: ណាហ្គាសាគី 9 / ណាហ្កាសាគី 3 / ណាកាសាគី 1。
- Wiktionary は 漫画 の見出しを ម៉ានហ្គា とし、km-IPA 引数は `ម៉ាន-ហ្កា`(=/maːn.ɡaː/)。km-IPA は `ហ្គា`=/ɡiə/、`ហ្កា`=/ɡaː/、`ហ្កុ`=/ɡoʔ/、`ហ្គុ`=/ɡuʔ/、`ហ្គោ`=/ɡoː/、`ហ្កោ`=/ɡao/ と読む(3-1 の表)。
- 母音との組み合わせで実例に多いのは が=ហ្កា/ហ្គា、ぎ=ហ្គិ、ぐ=ហ្គឹ/ហ្កុ、げ=ហ្គេ、ご=ហ្គោ/ហ្គុ/ហ្កុ。
- 含意: ADR-0010 で「ガ行は標準の読みの確認が要る」とされた点の根拠として、**書き手はほぼ ហ្ក と ហ្គ を区別せずに使っている**。

#### ざ行(z)・じ・ぢ・ず・づ

- ざ・ぜ・ぞ: **ហ្ស**(ហ្សា ហ្សូ)。宮崎 មីយ៉ាហ្សាគី、金沢 ខាណាហ្សាវ៉ា、象 ហ្សូ、絆 គីហ្សូណា、健三郎 ខេនហ្សាប៊ូរ៉ូ、晋三 ស៊ីនហ្សូ。
- **じ**: ជី / ជិ(ជីមមឹ、ហ្វឹជី、ហ្វឹជិវ៉ារ៉ា、សាកាម៉ូតូ រ្យូអ៊ីជី の ち)。じゃ・じょ は ចា・ចុ(ឆូចុ、ចុសេ)。じゅ は ជូ か ច៊ូ(ស៊ិនច៊ូគូ)。
- **ず・づ**: ហ្ស៊ូ(ស៊ូហ្ស៊ូគី 鈴木善幸)/ ហ្សឹ(ស៊ីហ្សឹអុកា、មីហ្សឹហូ)/ **សូ(濁らせない)**(សូសូគី)/ ហ្សូ(ទិហ្សូកា、គីហ្សូណា)。仮名表は ず・づ を「同音」として同じ綴り(ហ្ស៊ុ/ហ្ស៊ឹ)にする。**づ を含む語は今回の実例に無く**、ヅ の実例による裏付けは無い。
- **スズキ**: km-wp の ម៉ូតូ 記事は សូសូគី(ず を濁らせない)、鈴木善幸は ស៊ូហ្ស៊ូគី(仮名表と同じ型)。企業名のカンボジア報道は Latin(Suzuki)。**多数派は判定できない**(各 1 件)。
- **し(RFA 2022 の ហ្ស៊ិនហ្សូ)**: シンゾウ の シ を ហ្ស៊ិ(/zɨ/)で書いた例で、同じ RFA の 2018 年記事は ស៊ីនហ្សូ。同じ機関でも年で変わる。

#### だ行(d)

- ដ(a 系)が主: ហុនដា/ហុងដា、តូយ៉ូដា、ដេនសូ、ដូ(どう ហុកកៃដូ、នីនថេនដូ、ដូរ៉ាអេម៉ន)、ហាកុដាតេ、ដៃ(大雪 ដៃសិត្ស៊ឹហ្សាន់)、សាកលវិទ្យាល័យ 略称の ដាយ(だい)。仮名表は で に ឌេ も併記。
- km-IPA では ដ は内破音 /ɗ/(ហុងដា /hoŋ.ˈɗaː/)。
- **た行の有気/無気**: た・て・と に **ថ**(有気 /tʰ/)を使う例 = 田中 ថាណាកាសាំង、任天堂 នីនថេនដូ、東北 ថូហុគឹ。**ត**(無気)を使う例 = 田中 តាណាកា(km-wp)/ តាណាកាក់(km-wikt)、តូយ៉ូតា、តូក្យូ。同じ語(田中)でも ថា と តា が併存。
- **トヨタ**: ត(た)と ដ(だ): 会社名 តូយ៉ូតា、創業者名 តូយ៉ូដា(豊田)。

#### ば行・ぱ行(b, p)

- ば・べ・ぼ: ប(a 系: បា បិ បេ បុ)、び・ぶ: **ប៊**(o 系: ប៊ី ប៊ិ ប៊ូ)。例: វ៉ាសាប៊ី、យ៉ូអាសូប៊ី、អុប៊ិហ៊ិរ៉ុ、ខេនហ្សាប៊ូរ៉ូ、ឈីបា、កូបិ/កូបេ。km-IPA では ប も ប៊ も /ɓ/(内破音)。
- ぱ行: **ប៉**(សាប៉ូរ៉ូ、សាប់ប៉ូរ៉ូ、ប៉ាណាសូនិច、យ៉ូរ៉ុបប៉ា)。**ភ**(有気)を使う例 = ポケモン ភូកេម៉ុន(仮名表は ぴ・ぷ・ぺ に ភ・ព・ផ・ប៉ を併記)。km-IPA: ប៉ា=/paː/、ភូ=/pʰuː/。
- ヴ(ADR 対象外だが参考): カタカナ表は ヴ に វុ・វឹ、ヴァ に វ៉ា を併記。ヴィッセル神戸は វីសែល កូបេ(Wikidata)。

#### つ(ts)

- 実例: **ត្ស៊ឹ**(ណាត្ស៊ឹគិ、ម៉ាត្ស៊ឹម៉ូតុ、ដៃសិត្ស៊ឹហ្សាន់、គុស៊ិរ៉ុស៊ិត្ស៊ឹហ្គេន、ស៊ីកុត្ស៊ឹ-តូយ៉ា)/ **ត្សឹ**(ម៉ាត្សឹស៊ីតា、ត្សឹគឹបា、អ៊ឹត្សឹណុមិយ៉ា、មាត្សឹ〔km-wikt〕)/ **ហ្សឹ**(ម៉ាហ្សឹយ៉ាម៉ា 松山)/ **ស៊ូ**(ស៊ូណាមិ〔Wiktionary〕)/ **តស៊ូ・ត់ស៊ូ**(មីតស៊ូប៊ីស៊ី、អាត់ស៊ូស៊ី)/ **ថ្សឺ**(តូយ៉ូតា ថ្សឺស្សូ)。
- km-IPA: ត្ស៊ឹ=/tsɨ/(ɯ に最も近い)、ត្សឹ=/tsə/、ត្សា=/tsaː/、ស៊ូ=/suː/、ស៊ុ=/suʔ/(ts が落ちる)。
- ロシア語 царь を ត្សារ(Wiktionary)と書くので、**ត្ស は「ts」の書き方として外来語で既に存在する**(第4節)。

#### ふ(ɸ)

- 実例: ហ្វឹ(ហ្វឹជី、ហ្វឹគឹស៊ីម៉ា、ហ្វឹគឹអ៊ី、ហ្វឹជីសាវ៉ា、ហ្វឹជិវ៉ារ៉ា)/ ហ្វូ(ហ្វូគូស៊ីម៉ា、ហ្វូគូអូកា、ហ្វូមិអុ、ហ្វូសាជីរ៉ូ、ហ្វូជី)/ ហ្វ៊ូ(ហ្វ៊ូជិហ្កុ、ហ្វ៊ូគូអូកា、ហ្វ៊ូជី)/ ហ្វុ(ម៉ាហ្វុម៉ាហ្វុ、ហ្វុរុដាតេ)/ ហ្វ៊ុ(ហ្វ៊ុមិអុ)/ ហ៊្វុ・ហ៊្វូ(ហ៊្វុមិអុ、ម៉ាសាហ៊្វូមី)。仮名表は ហ៊្វុ・ហ៊្វឹ(ひらがな)、ហ៊ុ・ហ៊ឹ(カタカナ)を併記。
- **同じ福島・福岡でも県名と大学名・クラブ名で ហ្វូ/ហ្វឹ が割れる**。
- km-IPA: ហ្វូ=/fou/、ហ្វ៊ូ=/fuː/、ហ្វឹ=/fə/、ហ្វុ=/foʔ/、ហ្វ៊ុ=/fuʔ/。**いずれも /f/ で /ɸ/ ではなく**、「ふ」に最も近い母音は ហ្វ៊ូ /fuː/ か ហ្វ៊ុ /fuʔ/(o 系 ◌៊)。実例では ហ្វ៊ូ より ហ្វឹ・ហ្វូ の方が多い。

#### し・ち・じ

- し: **ស៊ី/ស៊ិ**が標準。しゃ=សា/ស្សា、しゅ=ស៊ូ/ស្ស៊ូ/ស្សឺ(ឃ្យូស្ស៊ូ、ឃ្យឺស្សឺ)、しょ=ស្សូ/ឆូ/សុ(ស្សូអ៊ីឈីរ៉ូ、ឆូនេន、仮名表 ស្សុ・សុ)。RFA 2022 のみ ហ្ស៊ិ。
- ち: **ឈី/ឈិ**(ឈីបា、ខូឈិ、អៃឈិ、យ៉ាម៉ាហ្គឹឈិ、សេអ៊ីឈី)/ **ជី/ជិ**(ហុងដា សូអ៊ិជិរ៉ូ、រ្យូអ៊ីជី សាកាម៉ូតូ)。じ は ជី/ជិ(ហ្វឹជី、ហ្វូសាជីរ៉ូ、ជីមមឹ)。ちゃ・ちょ=ចា/ឆា(ចាំង、គុតចាន់)、ឆូ/ចុ。km-IPA: ឈី=/cʰiː/、ជី=/ciː/。
- しゅう→ស្ស៊ូ、しょう→ស្សូ のように、**シ系の拗音は ស្ស(ស+ស)で書く**書き手がいる(仮名表・km-wp)。km-IPA は ស្ស を「ss」と誤読するため、この綴りは読み側で不安定(未検証)。

#### 拗音(きゃ・きゅ・きょ・りゃ…)

- 型は「子音字+្យ+母音記号」で一貫: きょう→ក្យូ(តូក្យូ、ក្យូតុ)、きゅう→ឃ្យូ/ឃ្យឺ/ខ្យូ(ឃ្យូស្ស៊ូ、ឃ្យឺស្សឺ、ហៃគ្យូ)、りゅう→រ្យូ/រ្យឺ(រ្យូគ្យូ、រ្យឺឃ្យឺ)、りょ→រ្យ、ちゃ→ចា/ឆា。
- km-IPA: ក្យូ=/kjou/(a 系 + ូ → /ou/)、គ្យូ/ឃ្យូ=/kjuː/、ឃ្យឺ=/kjɨː/、ក្យុ/ខ្យុ=/kjoʔ/。
- **系列**: a 系 + ្យ は /kjou/(きょう に近い)、o 系 + ្យ は /kjuː/(きゅう に近い)。実例は きょ を a 系(ក្យ・ខ្យ)、きゅ を o 系(គ្យ・ឃ្យ)で書き分けている。
- 長音の ូ と ឺ は同じ語で割れる(きゅうしゅう: ឃ្យូស្ស៊ូ〔島の記事〕と ឃ្យឺស្សឺ〔大学の記事〕)。

#### 促音(っ)

- 型 (a) **前の音節の末に 次の子音と同じ字+់**(ត់ ប់): ណាត់តូ(納豆)、យ៉ាត់តា(やった)、សាប់ប៉ូរ៉ូ(札幌)、អាត់ស៊ូស៊ី(Atsushi)。
- 型 (b) **同じ字をそのまま重ねる**(់なし): ហុកកៃដូ、វ៉ាកកាណៃ、ហុកក្យូដាយ(ក+ក)、យ៉ូរ៉ុបប៉ា(ប+ប៉)、អ៊ីសសេ(ស+ស)、គុតចាន់・អេតឈិ(ត+ច/ឈ)。
- 型 (c) **書かない**: សាប៉ូរ៉ូ(km-wp の北海道記事。同じ札幌が Wikidata では សាប់ប៉ូរ៉ូ)。
- 型 (d) ក់ を**語末・助詞末の短母音の後ろに付ける**(km-wp の ភាសាជប៉ុន 記事の `វ៉ាក់`、`ហ្គាក់`、`…តាក់`)。これは促音ではなく短い開音節の印で、促音と区別されていない。
- ADR-0010 の想定(閉音節の末子音 p t k で近似)に近い型が (a)(b) で、**実例は同じ字を 2 回書く (b) の方が多い**(表の行数で 6 対 4)。

#### 長音

- ー: `រ៉ាមេន`(ラーメン)は ា だけ、`សូនី`(ソニー)は នី、`ស៊ូម៉ូ`(すもう)は ម៉ូ。**長音記号に対応する専用の字は無い**。
- おう・おお: ូ(តូក្យូ、ហុកកៃដូ)、អូ(អូសាកា、ខេត្តអូសាកា、អូស៊ីន)。
- えい・せい: េ のみ(សេនេន、សេអ៊ីឈី では សេ+អ៊ី と i を残す例も)。
- ゅう・ょう: ូ または ឺ(ឃ្យូ と ឃ្យឺ)。
- 長短を書き分ける書き手は見当たらず、長音の書き分けは対応表側で新たに決める必要がある(ADR-0010 と同じ結論)。

#### 撥音(ん)

| 綴り | 環境と実例 |

| **ន** | 語中の t・s・z・n・g の前と語末: អុនសេន、ហុនដា、នីនថេនដូ、ស៊ីនហ្សូ、ខេនហ្សាប៊ូរ៉ូ、ម៉ានហ្គា(g の前)、ភូកេម៉ុន、រ៉ាមេន |

#### ら行

- 標準: **រ+៉(a 系)**: រ៉ា(រ៉ាមេន、ណារ៉ា、ខារ៉ាអូខេ、សុរ៉ារុ)、រ៉ូ(ហ៊ីរ៉ូស៊ីម៉ា、សាប៉ូរ៉ូ、ខេនហ្សាប៊ូរ៉ូ)、រ៉ុ(មុរ៉ុរ៉ាន់、នេមុរ៉ុ、អុប៊ិហ៊ិរ៉ុ)。
- **រ(o 系)**: រិ រុ(ស៊ិរិតុកុ、អាការិ、សុរ៉ារុ、ណារុហ៊ីតុ、ហ្វុរុដាតេ)。
- **ល・ឡ**: យូនីគុលូ(ユニクロ の ロ)、ឡេអ៊ីជិ(零士 の れ)。km-wp の仮名表は カタカナの ラ行 に ឡ・ល を併記。
- km-IPA: រ៉ា=/raː/、រ៉ូ=/rou/、រុ=/ruʔ/、រូ=/ruː/、លូ=/luː/、ឡូ=/lou/。
- ろ の揺れ: ろ=រូ(គូរូគី)と រ៉ូ(គូរ៉ូគី)が同じ RFA 記事内で併存。

#### や行・わ行

- や=យ៉ា(ម៉ូតូយ៉ាម៉ាហា、យ៉ាម៉ាហ្កាតា)、ゆ=យូ(យូនីគុលូ、យូរិ)、よ=យ៉ូ(តូយ៉ូតា、យ៉ូអាសូប៊ី)/ យ៉ុ(យ៉ុកុហាម៉ា、ខ្រែយ៉ុន)/ យូ(យូកូហាម៉ា、សាយូណារ៉ា)。**よ は យ៉ូ・យ៉ុ・យូ の 3 型**。
- わ=វ៉ា(វ៉ាសាប៊ី、អ៊ីវ៉ាតិ、ហ្វឹជិវ៉ារ៉ា)。助詞 は=វ៉ាក់(km-wp)。を=អុ/វ៉ុ(仮名表の注記のみ)。
- km-IPA: យ៉ា=/jaː/、យូ=/juː/、យ៉ូ=/jou/、យ៉ុ=/joʔ/、វ៉ា=/ʋaː/(唇歯接近音)。

### 3-4. 対応表づくりへの含意(以下は観察からの推論であり、決定ではない)

1. **系列選択は確立している**: あ=a 系+ា、い=o 系+ី、う=o 系+ូ/ឹ、え=a 系+េ、お=a 系+ូ か o 系+ោ。`◌៉`(ម៉ រ៉ យ៉ វ៉ ប៉)と `◌៊`(ស៊ ហ៊ ប៊)で系列を切り替える方式は、実例・外来語・km-IPA のすべてで整合する。ADR-0010 のあ〜お割当(a 系だけ・o 系だけでは 5 母音が揃わない)を裏づける。
2. **綴りの自由度が大きいのは 母音の長短・ん・つ・ふ・が行**。書き手が揺れているので、どれかを規約として決めるしかない(慣習を採るだけでは決まらない)。
3. **km-IPA で /ɡaː/ になるのは ហ្កា で、ហ្គា は /ɡiə/**。km-wp の書き手は ហ្គា を「ガ」に使うことが多いので、実際に話者が ហ្គា をどう読むかを聞く必要がある(未確認)。
4. **促音**は ត់・ប់・ក់ を前音節に付ける型 (a) と、同じ字を重ねる型 (b) の 2 つが実例にあり、外来語(フランス語)の語末閉鎖音の書き方(ក់ ត់)とも一致する。
5. **つ**は ត្ស៊ឹ(/tsɨ/)が音として最も近い。ត្ស はロシア語借用語(ត្សារ)で既に「ts」を表すので、新しい字を作らなくても書ける。
6. **ふ**は [f] にしかならず、母音を ូ(/fou/ か /fuː/)にするか ឹ(/fə/)にするかで揺れる。ɸ を右肩 IPA で補う ADR-0010 の方針と矛盾しない。
7. **日本の国名 ជប៉ុន はフランス語 Japon 由来**(Wiktionary)で、「ニホン/ニッポン」の音写ではない。国名・言語名は対応表と別に扱う必要がある。

日本語への含意(推論):
- **g・z・f は ហ + coeng の補助子音で書く**(が=ហ្គ/ហ្ក、ざ=ហ្ស/ហ្ស៊、ふ=ហ្វ/ហ្វ៊)。日本語借用語の実例(第3節)と一致しており、書き手は外来語の型をそのまま日本語に適用している。
- **b・d・t・s・z・f・g などは「母音に合わせて a 系/o 系を選ぶ」** のが外来語の通例で、日本語の実例(ស៊ី ហ៊ី ប៊ី ហ្ស៊ូ など)と同じ規則で動く。
- **ts は ត្ស**(ロシア語)、**語末の p・t・k は ប់ ត់ ក់**(フランス語)、**ん に近い n・ŋ・m は ន・ង・ម、鼻母音は ង់**。
- **日本語の ʃ(し)・ɸ(ふ)・ɯ(う)**に専用字は無い。外来語でも ʃ は ស で代用され、f は [f]。
- **ដ と ឌ の使い分け**(a 系/o 系)は外来語に明確にあるが、日本語の実例では ដ(a 系)ばかり(ដូ ដា ដេ)で、ឌ は仮名表の候補(で=ឌេ)に留まる。日本語では di・du が無いので、この使い分けは日本語では表に出ない。
- **l と r の書き分け**: 外来語は l=ឡ、r=រ で書き分けるので、日本語の ら行(実際は弾き音)を រ か ល/ឡ にするかは、話者ごとの読み(プノンペン方言では រ が口蓋垂化/脱落。ADR-0010 参照)で決まり、外来語の規則からは決まらない。
- 王立アカデミーは 2021 年時点で外来語の綴りの標準化に着手した段階で([r_rac])、Chuon Nath 辞典の外来語規則の原文は今回入手できなかった。

### 5-4. 使う際の注意

- **km-wp の件数**は MediaWiki 検索 API(`list=search`, `"語"` 完全一致)の総ヒット記事数で、話者一般の使用頻度ではない。同じ語が複数の記事に現れると数が増え、クメール語の分かち書きの無さから部分一致が混じる可能性がある。
- **km-wp は個々の編集者の実践**で、記事間で同じ語が違う綴りになる。参考にする綴りは、機械翻訳的な文が混じる ភាសាជប៉ុន 記事(助詞の ក់ など)と、地名・大学記事(整った表)とで性格が違う。
- **RFA は記者・年ごとに揺れ**(安倍: ស៊ីនហ្សូ 2018 / ហ្ស៊ិនហ្សូ 2022、岸田: ហ្វូមិអុ / ហ្វូមីអូ を同年に併用、黒木: គូរ៉ូគី / គូរូគី を同一記事内で併用)、ラテン綴りが併記されるので、ラテン綴りとの対応で日本語の音を確認できる。
- **km-IPA は Wiktionary のモジュール出力**で、話者の実音ではない。単語全体を入れる場合は音節境界を手で入れないと誤る。
- **未確認**: ネイティブ話者による読みの確認、ラテン綴りが併記されない語(km-wp 人名記事の多く)の日本語の正しい音、Huffman・Headley との照合、Google Maps・現地看板。
