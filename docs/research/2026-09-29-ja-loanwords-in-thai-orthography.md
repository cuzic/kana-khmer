# 日本語(カタカナ発音)→タイ文字の表記慣習と公式基準の調査

調査日: 2026-09-29。調査者: 調査エージェント(リポジトリの他ファイルは編集していない)。
目的: 計画中の `ja-thai`(日本語の発音=カタカナ → タイ文字。タイ人の学習者・日本旅行者向け)の対応表と方針を決める根拠として、(1) 公式の音写基準、(2) 実際の綴りの慣習と揺れ、(3) 声調をどう扱えるか、(4) 学習者研究、を集めた。書式は `2026-09-28-ja-loanwords-in-khmer-orthography.md` に合わせた。
方針: 推測でタイ文字を作らない。表のタイ文字はすべて、出典で見たものを書き写した(出典欄は末尾の参照定義に対応)。備考の「公式と一致/異なる」は、調査者が官報の規則・例と突き合わせた比較で、出典の主張ではない。取得できなかったことは第6節に書いた。
取得の注記: 官報の PDF・各ページ本文は `curl` と `pdftotext` で原文を取り、必要な表はページ画像でも確かめた(検索ツールの要約は数値や表を取り違えることがあったため、要約だけに頼った項目は第6節に「原文未確認」と書いた)。

### 1-2. 比較的確立している(公式・th-wp・Wiktionary・学習サイトの大半で一致)

1. **公式基準が現行の根拠として通用している**。th-wp の記事名・Wiktionary 見出しの地名・料理名の多くは、官報の例・規則と同じ綴りになる(実例表の備考に「公式の例と一致」と記した行が該当。例: 抹茶 มัตจะ、天ぷら เท็มปูระ、津波 สึนามิ、岐阜 กิฟุ、水 มิซุ、山葵 วาซาบิ、俳句 ไฮกุ)。
2. **子音字**: ら行=ร(全出典で ล は 1 例もなし)、さ行=ซ、し=ชิ(公式表・かな表・実例のすべて。ただし一部に ซิ・ซโย の揺れ、1-3)、は行=ฮ、や行=ย、わ=ว、な行=น、ま行=ม、ば行=บ、だ行=ด、ず=ซุ・ซู。ぱ行は語頭で พ(パナソニック พานาโซนิค、ポン酢 พนซุ)と ป(ポケモン โปเกมอน、ポッキー ป๊อกกี้、パスポート ปะสุโปโตะ)に割れ、語中は ป(ซัปโปโระ、เท็มปูระ)。
3. **語頭の無声閉鎖音は有気字、語中は無気字**(か=ค→ก、た=ท→ต、ぱ=พ→ป、ち=ช→จ)。これは公式規則 7 の明文で、th-wp・Wikt の地名(ค: คูมาโมโตะ/ก: อากิตะ 等)にも現れるが、**学習サイトでは崩れる**(BestKru は か行=ค・た行=ท・が行=ก を語位置に関係なく一律に書く。KTC は 語中でも นิคุ・ทามาโกะ)。
4. **定着語は規則より優先される**。公式規則 19 が โตเกียว・เกียวโต を明記(規則どおりなら โทเกียว・เคียวโตะ)。
5. **長音は書き分けない**。公式規則も、長母音は「長母音」、開音節の短母音(語末以外)も「長母音」で書くので、おかさん(okasan)と おかあさん(okāsan)の区別は綴りに現れない(公式の例 okāsan=โอกาซัน)。実務側も、อะริกาโตะ・โอะฮาโย のように書き手が任意に ะ を付けるだけで、長さを区別する体系はない。MATCHA のみ、ローマ字側で「:」を長音記号にし、タイ文字側で ไม้เอก を当てる実験的な扱い([MATCHA] の dezai na / dezai na:)。
6. **ん は後続音で น/ง/ม を選ぶ**(公式・JapWithUs・KTC・Sanook の説明・実例が一致): m・b・p の前=ม(คมบังวะ、เท็มปูระ、กุมมะ)、g・k・h・w・y の前=ง(เด็งวะ、กิงโก、โอะเก็งกิ)、ch・d・j・n・r・s・sh・t・z の前=น(คันจิ、เอ็นโด)、語末=ง または น。
7. **促音は「前の音節の末子音字+次の子音字」の重ね書き**(กักโก、ซัปโปโระ、ฮกไกโด、โชตโตะ)。閉音節の短母音は สระอะ の ั または ็、o は母音記号なし(公式の「ลดรูป」)。
8. **つ**: 語頭・子音の後=สึ、母音の後=ตสึ が公式。th-wp・Wikt の実例はこれに一致(สึนามิ、มัตสึยามะ、ฟูจิตสึ、ทงกัตสึ)。

### 1-4. 声調(詳細は第4節)

- タイ語の声調は、**子音字の3類(高・中・低)・母音の長短・末子音の有無(生き音節/死に音節)・声調記号**で決まる。カタカナ→タイ文字の対応表を作ることは、そのまま**各音節の声調を選ぶこと**になる。日本語の高低アクセントは綴りに現れず、綴りが決めた声調がそのまま読み手に聞こえる。
- **Wiktionary の th-pron は、`action=expandtemplates`(または `action=parse`)で任意のタイ文字列の IPA・声調を取得できる**。ただし**音節をハイフンで区切って渡す必要がある**(区切りなしだと「Entries with failed Thai transliterations」に落ち、IPA が空になる)。実行例と結果は 4-2〜4-4。
- pythainlp(v5.3.8)の `tone_detector`/`sound_syllable` はオフラインで使えるが、**阻害音の後の เ-/โ-/แ-/-อ の開音節(日本語のお段・え段の中心的な音節)を死に音節と誤判定**する(th-pron と比較した 67 音節中 7 音節が食い違い、すべてこの型。追加の 47 音節では 19 音節。4-5)。

### 1-5. 学習者研究(詳細は第5節)

- 日本語の無声閉鎖音の VOT は、短いラグと長いラグの**中間**(Riney ほか 2007: p 30.0・t 28.5・k 56.7 ms。検索結果の要旨から)。タイ語は有声(前有声)・無気(短ラグ)・有気(長ラグ)の3系列。**公式規則 7(語頭=有気字、語中=無気字)は、この中間性に対する折衷案と読める**(推論)。
- タイ語母語話者の日本語では、**語頭のガ行、ガ行とカ行の弁別、促音(聞き取りで促音と聞く偏り)、破擦音ツ、ピッチアクセント**が問題として研究されている。タイ語は母音の長短が音素で末子音の /p t k/ が解放されない、という素地がある(en-wp)が、長音・撥音についてタイ語話者に限った実験は今回未確認。

### 1-6. 設計への含意(観察からの推論であり、決定ではない)

- 表記の基準には **公式 2018 年版を骨格にする**のが根拠として最も強い。ただし公式は「ローマ字→タイ文字」の規則で、**カタカナの音を直接扱っていない**(です・ます・助詞(は=wa、を=o)の例が無い、外来語音(ティ・ファ 等)の扱いが無い、官報の子音表に r の行が無い、など。第3節)。ja-thai は、カタカナ→ローマ字(ヘボン式)→公式規則、の二段で組むのが最短。
- **長短の書き分けがタイ語側に無く、公式も潰す**ので、長音の情報を別の手段(記号・注記・音声)で持つかどうかの決定が要る。
- **声調は綴りの選択の副産物**。同じ「か」でも ก(กะ ˨˩)と ค(คะ ˦˥)で声調が違う(4-4)。日本語のアクセントを声調で近似するか、声調が「意図せず付いてしまう」影響を最小にする綴りを選ぶか、方針を立てる必要がある。
- ふ(ฟ/ฮ)、つ(สึ/ตสึ/ทสึ)、し・ち・じ、が行(ก/ง)は、公式に合わせる根拠はあるが、**学習者向けの資料ではこの通りになっていない**。学習者の見慣れた綴りに寄せるか公式に寄せるかは、ADR に起こす価値がある論点。

## 2. 実例表

- **モーラ列の表記**: `.` はモーラ区切り(語の切れ目は空白)、`:` は長音、`q` は促音、`n` は撥音。人名は名・姓の順が出典の綴りと同じになるようにした。
- **出典欄**: `tw*`=タイ語版 Wikipedia の記事名(記事の URL が参照定義)。`wk*`=英語版 Wiktionary のタイ語見出し(見出し名に語源欄の日本語が付いているもの)。KTC・Wongnai・Sanook・Pawano・MATCHA・BestKru・JapWithUs は学習サイト・解説記事(第2-6節)。
- **タイ文字**列は出典に書かれた文字列をそのまま写した。th-wp の記事名にある曖昧さ回避(เมือง)と、訳語の接頭語(จังหวัด・ภูเขา・ยุค・ปราสาท・ตลาดปลา・เขต・ภาษา)は備考に記して取り除いた。
- **備考の「公式の例と一致」**: 官報の規則の例(Fuji=ฟูจิ、Gifu=กิฟุ 等)と同じ文字列になるもの。「公式の規則と一致」は例はないが規則どおりのもの。

| -yu | –ิว | byuffe บิวเฟะ(外来語に多い、との注) |
| -yū(yuu) | –ีว | kyūkō คีวโก |

- 注: -yo・-yu で末子音字があれば、ว が末子音を兼ねるので**末子音字は省く**。しゃ・しょ・ちゃ・じゃ 等は sh・ch・j の行で扱う(例 Shōwa โชวะ)。

### 3-6. 公式基準の性質(調査者の観察)

1. **長短の対立は綴りに出ない**。okasan(お・か・さん)と okāsan は、どちらも `โอกาซัน`(4.1 と 5 の効果)。ローマ字で ō と o を書き分けても、開音節では -โ で同じになる。語末の短母音だけが -ะ・-ิ・-ุ・เ–ะ・โ–ะ として短く現れる。
2. **子音の有気・無気は「語位置」で決める**(規則 7)。したがって、**カタカナ1文字に対応するタイ文字が語位置で変わる**(か=ค または ก、た=ท または ต、ぱ=พ または ป、ち=ช または จ)。かな表としての1対1は作れない。
3. **ん・が行・つ に「可」が多い**(นิปปน/นิปปง、โจมน/โจมง、อาริงาโต/อาริกาโต、คิซซาเต็น/คิซซาเต็ง)。規則は「どちらでもよい」を許し、一意に決まらない。
4. **です・ます・助詞(は=wa、を=o)の例は官報に無い**。規則を機械的に当てはめれば です=เดซุ になるが、官報の例ではなく、実務の綴りとも異なる(第2-8節)。
5. **母音の無声化とアクセントは扱わない**(原則 1)。
6. **外来語音**(ティ・ファ・ヴ 等のカタカナ)の扱いは無い(表はヘボン式の 5 母音+子音の範囲)。
7. 定着語(規則 19)の例外があり、**同じ日本語がもとの規則と異なる綴りで公認される**(โตเกียว・เกียวโต)。ja-thai の対応表がこれらを例外として持つ必要がある。

## 4. 声調と th-pron の調べ方

### 4-1. タイ語の声調の決まり方(Module:th-pron のデータ)

Wiktionary の `Module:th-pron`(Lua)が使う声調表は、次のとおり(モジュールの `tFromMark`・`tNoMark` の表をそのまま書き写した): [Module:th-pron] — 声調記号が無い場合(`tNoMark`)と、ある場合(`tFromMark`)。

| 声調記号 | 高類子音字 | 中類子音字 | 低類子音字 |
|---|---|---|---|
| なし・生き音節(長母音で終わる、または鼻音・半母音の末子音) | 上昇 | 中 | 中 |
| なし・死に音節・短母音(短母音で終わる、または p t k の末子音) | 低 | 低 | 高 |
| なし・死に音節・長母音(長母音+ p t k) | 低 | 低 | 下降 |
| ่(ไม้เอก) | 低 | 低 | 下降 |
| ้(ไม้โท) | 下降 | 下降 | 高 |
| ๊(ไม้ตรี) | 高 | 高 | 高 |
| ๋(ไม้จัตวา) | 上昇 | 上昇 | 上昇 |

- 子音字の類は同モジュールの `initial` 表に持たせてある(例: ก จ ด ต บ ป อ=中、ข ฉ ถ ผ ฝ ส ห=高、ค ช ซ ท พ ฟ ฮ ง น ม ย ร ล ว=低。`initial` 表で確認)。
- **日本語→タイ文字の対応表にとっての意味**: ①短母音で終わる音節(語末の -ะ・-ิ・-ุ、および i・u を常に短く書く官報の規則で、語中の ชิ・มิ・นิ・ริ も)は死に音節になり、**類で声調が決まる**(低類=高、中類・高類=低)。②開音節の長母音(-า -ี -ู เ- โ- ไ-)は生き音節で、**中類・低類は中声調**。③ไม้เอก・ไม้ตรี を付けると**声調が強制的に変わる**(商標表記の ยามาฮ่า ฮ่า=下降、ホンダ ด้า=下降 など)。④日本語のピッチアクセントは綴りに現れず、綴りが選ぶ声調がそのまま読み手に聞こえる。

### 4-2. th-pron を API から呼ぶ(実行した例)

`{{th-pron|…}}` は Wiktionary のテンプレート([th-pron])で、`Module:th-pron` を呼ぶ。API のエンドポイントは [Wikt API]。MediaWiki の `action=expandtemplates`(または `action=parse`)で、**任意のタイ文字列を渡して IPA と声調を得られる**。実行は 2026-09-29。

```
curl -s -G 'https://en.wiktionary.org/w/api.php' \
  -A 'kana-khmer-research/0.1 (contact)' \
  --data-urlencode 'action=expandtemplates' \
  --data-urlencode 'format=json' \
  --data-urlencode 'prop=wikitext' \
  --data-urlencode 'text={{th-pron|ซู-ชิ}}'
```

- 応答の `expandtemplates.wikitext` は HTML の表で、`<span class="IPA">/suː˧.t͡ɕʰiʔ˦˥/</span>` と、ローマ字2種(`<span class="tr">suu-chí</span>` = Paiboon、`su-chi` = Royal Institute)を含む。**結果: `/suː˧.t͡ɕʰiʔ˦˥/`(ซู=中 ˧、ชิ=高 ˦˥)**。`title` パラメータは不要だった。
- `action=parse`(`prop=text`、`contentmodel=wikitext`、`title=ซูชิ`、`text={{th-pron|ซู-ชิ}}`)でも同じ IPA を得た。
- **音節をハイフンで区切って渡す必要がある**。区切りなしの `{{th-pron|ซูชิ}}` は、`Category:Entries with failed Thai transliterations` に落ち、IPA が空になる。今回、区切りなしで失敗した語: ซูชิ・ซากุระ・โตเกียว・เกียวโต・ราเม็ง・ฮอนด้า。単音節(ซู・ชิ・คา・เดะ)は成功。Wiktionary の実際の見出しも、`{{th-pron|ซู-ชิ}}` のように編集者が手で区切っている(第2-5節の備考)。
- **ja-thai がタイ文字列を作る時点で音節区切りも一緒に持てば、th-pron で声調を検証できる**。区切りなしの文字列は今回の試行では動かなかった。
- `-A` に連絡先を付けて呼んだ。レート制限には当たらなかった(200 回を超える呼び出し)。

Python で呼ぶ最小の形(標準ライブラリのみ):

```python
import json, re, urllib.parse, urllib.request
def th_pron(hyphenated):
    p = {"action": "expandtemplates", "format": "json", "prop": "wikitext",
         "text": "{{th-pron|%s}}" % hyphenated}
    req = urllib.request.Request("https://en.wiktionary.org/w/api.php",
        data=urllib.parse.urlencode(p).encode(),
        headers={"User-Agent": "kana-khmer-research/0.1 (contact)"})
    w = json.load(urllib.request.urlopen(req, timeout=60))["expandtemplates"]["wikitext"]
    return re.findall(r'<span class="IPA">(.*?)</span>', w)   # 失敗時は "Category:Entries with failed..." を含む
```

### 4-5. Python ライブラリ pythainlp(オフライン)

- 入れ方: `uv run --with pythainlp python …`(v5.3.8)。声調に使える関数は `pythainlp.util.sound_syllable(syllable)`(`"live"`/`"dead"`)と `pythainlp.util.tone_detector(syllable)`(`"l"` 低 / `"m"` 中 / `"f"` 下降 / `"h"` 高 / `"r"` 上昇)。1音節を渡す。**音節分割**は `syllable_tokenize` の既定エンジンが `python-crfsuite`(`pycrfsuite`)を要求し、入れないと `ImportError`。`subword_tokenize(engine='tcc')` は動くが、**閉音節・促音を音節としてまとめられない**(下)。ローマ字化は `romanize(engine='royin')`。[pythainlp]
- **th-pron との照合**(71 音節を両方に通し、th-pron が失敗した 4 語(単音節でないもの: ตสึ・ตซู・ทสึ、単独では成立しない ชั)を除く 67 音節): **60 音節が一致、7 音節が不一致**。不一致は すべて、**開音節の長母音 เ-・โ- を死に音節と誤判定**した例(โต เก โก โด โป เซ เท。pythainlp は 低 または 下降 と返すが、th-pron は 中)。
- 追加の 47 音節(เ-・โ-・แ-・-อ の開音節、ไ-、-า、短母音)で試すと、**28 一致、19 不一致**。不一致は すべて、**阻害音(ก ต ด ป ช ซ ท ค ฮ …)の後の開音節の長母音 เ- โ- แ- -อ**(โต เก โก โด โป โช เซ เท เฮ โซ โค เค เต เป เบ แก แต ตอ กอ)。鼻音・半母音の後(โม โน โอ โย โฮ โร เม เร เน)は一致。**ไ-・-า・短母音+ะ/-ิ/-ุ は全部一致**。
- **含意**: 日本語のお段・え段(公式の 4.1 で開音節が長母音になる)は ja-thai の中心的な音節で、**pythainlp の声調は最も使いたい音節で誤る**。オフラインで使うなら自前の声調規則(4-1 の表)を実装するほうが確実。
- `romanize(engine='royin')` は、ซูชิ→suchi、ซากุระ→sakura、โตเกียว→tokiao、สึนามิ→suenami、ฟูจิ→fuchi、อาริกาโตะ→arikato、ฮอนด้า→honda、ซัปโปโระ→sapporo、ฮกไกโด→hokkaido、เท็มปูระ→thempura と返す。**促音の重ねは誤る**(นิปปง→nipapong)、ん の閉音節は ฮนชู→honchu と返し、**การันต์ の無い ราเม็ง 系は問題ないが、ะ の後ろ(คาราโอเกะ)は `kharaokeะ` と ะ が残る**。`tcc` の分割は ฮอนด้า→[ฮ, อ, น, ด้า]・นิปปง→[นิ, ป, ป, ง]・ฮกไกโด→[ฮ, ก, ไก, โด] と、閉音節で切れる。つまり **ja-thai は音節分割を自前で持つ必要がある**。

## 5. 学習者研究

**先に**: タイ語母語話者の日本語音声の研究は多くが日本語・タイ語で、全文に当たれたのは一部。**数値を原文で確認できたものと、他の文献の引用として確認したものを分けて書く**。

### 5-1. 閉鎖音の VOT(有声・有気・無気)

| 項目 | 内容 | 出典 | 確認の程度 |
|---|---|---|---|
| タイ語の閉鎖音 | **3系列**: 前有声 /b d/、無気(短ラグ)/p t k/、有気(長ラグ)/pʰ tʰ kʰ/。タイ語の有声は常に負の VOT、無気は短ラグで英語の有声に並び、有気は長ラグで英語の無声有気に並ぶ | [LEARN 2025] (Table 3 と本文。Lisker & Abramson 1964・1970 を引用)/ [Lisker 1964] | 原文(PDF)で確認。**タイ語の VOT の数値は今回未取得** |
| 日本語の語頭無声閉鎖音 | **短ラグと長ラグの中間**。単音節語の語頭で p 30.0 ms、t 28.5 ms、k 56.7 ms(日本語モノリンガル話者、キャリア文) | [Riney 2007] / [Riney 2007(要旨)]（要旨ページが 403 のため、検索結果に出た要旨の数値。書誌は DOI(Crossref)で確認: J. Phonetics 35(3): 439–443） | **数値は要旨の再引用。原文未確認** |
| 学習者の困難(ガ行とカ行) | 大沼 2022(高知高専紀要 68 号)は、「タイ語に [ɡ] が無い」「日本人向けのタイ語教科書は、タイ語の [k] を『ゴォー(K は濁点がつく発音)』『カ行をややガ行よりの音で』と説明する」「タイ語話者はタイ語の有気音 [kʰ] と [k] を明確に弁別する」ため、日本語の [k] を聞くとき、存在しないはずの [kʰ] との弁別を無意識に試みて混乱する、と整理する。先行研究として「語頭の /ガ/ 行が困難である」(平岩 2004 の引用)、「日本語の [ɡ] はタイ語にないため、英語の [ɡ] と説明する」(アサダーユット 2004 の引用)を挙げる | [Onuma 2022] | 原文(PDF)で確認。**引用元の原文は未確認**。研究の主眼は化学の教科書の語彙分析で、ガ/カ弁別を測定する実験ではない |

- **公式規則 7 との関係(推論)**: 官報は「語頭の ch・k・p・t は有気、他は無気または軽い有気」と述べ、これを根拠に**語頭を有気字(ช ค พ ท)・語中を無気字(จ ก ป ต)**にする。Riney ほかの VOT は、日本語の語頭が「中間」であることを示し、官報の「有気」は単純化と読める。タイ語の [k] が「ややガ行寄り」に教えられている(大沼が引く教科書)ことも合わせると、**タイ語の ก は日本語の か行語頭に近い、という判断の余地がある**。ただし、これは音声実験の結果ではなく、私の読み。
- 学習サイトの BestKru は か行=ค、が行=ก(語位置に関係なく)で、KTC は語中の か行も ค(นิคุ・อิคุระ)で書く。**学習者向けの実務は官報の規則 7 より「か行=ค、が行=ก」に寄っている**(2-8)。

### 5-2. 長音・促音・撥音

| 項目 | 内容 | 出典 | 確認の程度 |

| 特殊拍の学習一般 | 日本語学習者は促音・長音・撥音の習得が難しく、母語の音節構造に影響される。誤りは脱落(切って→切て)と挿入(来て→来って)の両方。日本語母語話者は特殊拍を1拍として捉えるが、他の母語では1単位に感じられない | [JF 特殊拍]（戸田 2003『音声研究』7(2) の紹介。**タイ語話者に限った記述は無い**） | 原文(JF ページ)で確認 |

### 5-5. ja-thai への含意(推論)

- 学習者向けに**「日本語の音とどう違うか」を示す**なら、ガ行(語頭・語中)、促音、ツ、アクセントが主なずれの候補。長音・撥音は母語で補えるが、**綴りが長短を書き分けない**ので、別の手段が要る。
- 綴りの選択(k/g、ts)は、学習者研究上の困難点と一致する場所(ガ/カ、ツ)を含む。**ここは公式規則どおりにしても、学習者の実際の聞こえと一致するとは限らない**。
