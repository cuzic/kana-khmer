# 日本語→クメール文字スパイクの読み戻し検証(2026-09-28)

ADR-0010 決定7(a)(生成したクメール文字を独立のクメール文字→IPA 変換で読み戻す)の最初の実施。
対象は `tools/ja-khmer-spike` の**仮の対応表**。検証の「独立」は生成側の表・コードを参照しないという意味で、
**読み戻し側の正しさは Wiktionary の `Module:km-pron` に依存する**(ネイティブ確認・実音声は未実施)。

## 方法
- 読み戻し器: `Module:km-pron`(英語版 Wiktionary、UNESCO『Khmer pronouncing dictionary』準拠)の
  `syllabify`・`syl_analysis`・`sylRedist`・`initClus`・`rime`・`convert`(IPA)を JS に移植(`src/readback.mjs`)。
  子音表・母音表は Lua から機械抽出。既知の語(ភាសា→`pʰiə.saː`、ខ្មែរ→`kʰmae`)で移植を確認した。
- モーラ単位(`src/verify.mjs`): 全かな×(短・長・+ン・+ッ)+拗音、342 件。読み戻した IPA が、意図した日本語音の
  許容集合(子音・母音・長短・末子音)に入るかを見る。許容は「音声的に近い」までで、同一性ではない。
- 語単位(`src/verify-words.mjs`): JMdict 共通語 22,508 語。音節区切りを明示した読み(意図)と、区切り無し
  (実際に読まれる)の一致を見る。

## モーラ単位の結果と修正(242 → 336 / 342)
| 不一致の原因 | 修正 |
|---|---|
| 末子音の前の固有母音は長い ɑː になる(`កន`→kɑːn) | 短い a+末子音は `◌់` を付ける(`កន់`→kɑn) |
| 末子音の前の `◌ិ` は [ɨ] になる(`គិន`→kɨn) | 長い `◌ី` を使い、長さは右肩 `ː` で足す(`គីន`→kiːn) |
| ហ្គ は o系(a系の ガ は ហ្ក) | g: a系=ហ្ក、o系=ហ្គ |
| ហ្ស・ហ្វ の o系は `៊` を coeng の後ろに付ける | z・f の o系にそれを採用 |
| **ណ は a系**(私は ន しか無いと誤っていた) | n: a系=ណ、o系=ន(な・ね が書けた) |
| ច ជ はどちらも /c/(区別は系列だけ) | ch・j: a系=ច、o系=ជ。有声は右肩 `ᶾ` で書き分ける |
| ニ+ャ行は [ɲ] | ニャ行は ញ(a系は `ញ៉`)で、coeng+យ を使わない |
| 拗音の `◌៊` の位置 | 基底字が阻害音なら基底字の直後(`ហ៊្យ`)、共鳴音(ម យ រ វ)なら យ の後ろ(`ម្យ៉`) |

残る 6 件は ビャ・ビュ・ビョ(`ប្យ`→pʰj)。モジュールが `ɓ` を子音の前で `p` にする規則によるもので、
生成側では直せない。既知の弱点として残す(ADR-0017 の対応表の穴に足すべき項目)。
全かなの対応で、実質的な衝突は無くなった(残る 12 組はヲ/オ・ヂ/ジ・ヅ/ズ・ヴ/ブで、日本語でも同音)。

## 語単位の結果(未解決・要判断)
共通語 22,508 語のうち **3,607 語(16.0%)で、区切り無しの読みが意図とずれる**。読めない語が 1,414 語。
原因は、母音で終わる音節の直後に coeng の子音連続が来ると、前の音節の末子音に切り直される規則
(`sylRedist`)。内訳(ずれた語):
- ហ្ក ហ្គ ហ្ស ហ្វ(が・ざ・ふ行の語中): 2,509 語。例: ございます `ហ្គោហ្សៈ`→`ɡoːh.saʔ`(ゴ+h・サ)
- ត្ស(つ): 587 語
- coeng+យ(拗音): 511 語。例: とうきょう `ទោːគ្យោː`→`toːk.joː`

判断が要る点(本検証では決められない):
1. **ហ្ក ហ្គ ហ្ស ហ្វ**は借用語の慣習的綴りで、実際のクメール語話者は ហ្ を子音の一部として読む可能性が高い。
   モジュールの誤読は規則の一般化の限界で、実際の読者の読みとは違うかもしれない。
2. **拗音の coeng+យ** は、本来の規則どおり語中で「末子音+យ」と読まれる恐れがある。
3. 対策の候補(未検証): 語中の頭子音連続の前に区切りを置く、拗音は coeng を使わず別の書き方にする、
   末子音の位置に別の字を置く、等。どれもクメール語話者による読みの確認が要る。

これは ADR-0010 決定7(b)(クメール語話者の音読)に載せる最重要の確認項目になる。

## 制約
- 読み戻しは Module:km-pron 一つに依存する(2次資料)。`ɓ`→`p` のような規則は実際の発音と違うかもしれない。
- 「う」を `ុ`(o系、[u])にするか `ឹ`(o系、[ɨ])にするかは、どちらも読み戻しは通る(336/342 で同じ)。
  日本語の /ɯ/ にどちらが近いかは、聞き比べが要る(未実施)。
- つ(ត្ស)・ヴ・語末の「ンッ」等は対応が仮のまま。
