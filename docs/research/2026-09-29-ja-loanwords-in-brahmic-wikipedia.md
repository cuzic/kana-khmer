# 日本語の固有名詞・借用語の綴り: ブラーフミー系文字の Wikipedia(ヒンディー語・マラーティー語・ネパール語・ベンガル語・アッサム語)

2026-09-29。[ADR-0025](../adr/0025-ja-hi-ja-bn-notation-direction.md)・[ja-hi-spec.md](../ja-hi-spec.md) の表を決めるための、既存の綴りの集計。**綴りの頻度を数えただけで、話者の自然さの証拠ではない**。

## 方法

1. 英語版 Wikipedia の日本関連の記事名 402 件を用意した(hi.wikipedia の「श्रेणी:जापान」と下位カテゴリ(深さ3まで)の記事のうち英語版へのリンクがあるもの 307 件と、地名・文化語・企業名を手で挙げた約 150 件の和集合)。
2. 各言語版へ、英語版の言語間リンク(MediaWiki API `prop=langlinks`)で対応する記事名を引いた。件数は次のとおり(見つかった記事数): hi 331、bn 190、mr 137、ne 86、as 48(mai 14、sa 24、new 29 は少なすぎるので使わない)。
3. 英語版の記事名(マクロン付きヘボン式)を拍に分け、各言語版の記事名の文字と、同じ種類の拍・文字を順に対応づけた(**拍の数と文字の数が一致した語だけ**を数えた。同じ人物名の別記事は1回)。
4. 数えた項目: t・d(歯音かそり舌か)、s・sh(し・す等の文字)、短い u・i の母音記号、ん(子音の前)の書き方、ふ、ざ行、語頭の あ・お、あ段の ा の明示。

## 限界

- 記事名は編集者が付けた綴りで、英語版の記事名(英語風の綴り)に引かれる。人名が多く、英語で広く知られた語(東京・トヨタ・ホンダ等)は英語の綴り慣習の影響が大きい。
- 英語版の記事名の多くにマクロンが無く、長母音を数えられない(長音の集計はしていない)。u・i は、マクロン付きの ū・ī を含む語を除いても、マクロン無しで長い語(本州・九州・柔道 等。hi の u の集計から手で除いたのは hi のみ)が混ざる可能性がある。
- 自動の対応づけで、目視で照合したのは hi の t・d の一覧だけ。ne・as は母数が小さく(拍数が10未満の項目が多い)、傾向を言える数ではない。
- スクリプトはリポジトリに入れていない(手順は上のとおり再現できる)。

## 読み取れること

1. **hi の d はそり舌(ड)が多数派だが、他の言語(mr・bn)は歯音が多数派**。hi だけの傾向で、ja-hi-spec が d=ड を採るのは ヒンディー語に固有の判断。ja-bn・ja-mr は t・d とも歯音が既定になりそう(as はそり舌だが5語と3語)。
2. **ベンガル語は ু ি だけを使い、ূ ী を短い拍に使わない**。長い拍のある語(ū を含む2語)も ু で書かれ、**長短が綴りに出ない**。ADR-0025 の想定(ベンガル語は長音を明示する記法が要る)を支持する。
3. **ベンガル語は ん を ন্(7)か無印 ন(6)で書き、ং(アヌスヴァーラ)は0**。ন্ 固定が自然。
4. **ベンガル語・マラーティー語は s と sh を স/শ で書き分けている**(bn は s 20 : 0、sh 16 : 0)。読みが合流していても、**綴りの上では区別できる**。ADR-0025 が「s と sh を文字で分けにくい」と書いていたのは誤りで、直した(区別できるが、読みが合流している可能性は残る)。ネパール語の sh(し・しゃ)が स で書かれる例が多い(7 : 2)のは、拍数が少なく、確認が要る。
5. **ヒンディー語のヌクタ(ज़・फ़)は、ヒンディー語版 Wikipedia でも半数以上に使われる**が、ベンガル語には無い(জ়・ফ় は数えた範囲で0)。

## 長音の書き方(2026-09-29 追記)

英語版 Wikipedia の記事の冒頭文にある、マクロン付きのローマ字(「Tokyo (東京, Tōkyō)」の形)を取り、長い母音(ā ī ū ē ō)を含む語 66 件(マクロン付きが取れた記事のうち、対応する各言語版の記事があるもの)の記事名と、
en.wiktionary の「Hindi terms derived from Japanese」の由来欄のローマ字(マクロン付き 7 語)を、**目視で**照合した。拍の自動対応づけはしていない。件数は語の数で、語が少ない(hi 約 25、bn 約 17、mr 約 10、ne 約 5)。

### ヒンディー語(Wikipedia・Wiktionary)

- **ō・ē は、短い拍と同じ記号(ो े)で書く**。長さの印は付かない: कोबे(Kōbe)・क्योटो(Kyōto)・कान्तो(Kantō)・तोहोकू(Tōhoku)・टोक्यो(Tōkyō)・तोशिबा(Toshiba)・शोगुन(shōgun)・दाईम्यो(daimyō)・होक्काइदो(Hokkaidō)・कोफ़ू(Kōfu)・टोफ़ू(tōfu)。ヒンディー語の ो े は元から長めなので、長い/短い の区別が文字に出ない。**例外が1つ**: सुसुमु ओऽनो(Ōno)は長さに avagraha(ऽ)を使っている(1 記事のみ)。
- **ū・ī は長い記号(ू ी)で書くことが多いが、揺れる**: ू は क्यूशू(Kyūshū)・माशू(Mashū)・हांक्यू(Hankyū)・चूगोकू(Chūgoku)・जूडो(jūdō)・होन्शू(honshū)、ी は एओकीज़(Aokīzu)・कैंडीज(Kyandīzu)。
  一方、長い ū を短い ु で書く語もある(चुबू(Chūbu)・फ़ुजित्सु(Fujitsū)・युसाकु(Yūsaku))。**逆に、短い u・i を長い ू ी で書く語も多い**(सूशी・सूमो・सूनामी・फ़ूकूशिमा、नागासाकी の की 等。上の短い u の集計で 56 : 21)。**長短が文字で信頼して区別されているとは言えない**。
- **ā は ा で、短い あ と同じ**(रामेन(rāmen)・टाइगर्स(Taigāsu))。

### マラーティー語・ネパール語

マラーティー語は ū を短い ु で書く例が多い(चुबू・चुगोकू・क्युशू)。ō は ो 1 つ(कोबे・कांतो・तोहोकू・शोगुन)。ネパール語は語が少ない(क्योटो・कोची・ओइता・ह्योगो は ō/ō を ो 1 つ、नोह(Nō)は英語風に ह で終わる)。

### ベンガル語(Wikipedia)

- **半数近くは長さを書かない**(単独の ো ু ি): হিয়োগো(Hyōgo)・কিয়োতো(Kyōto)・শোগুন(shōgun)・টোকিও(Tōkyō)・তোশিবা(Tōshiba)・রামেন(rāmen)・আইকিদো(aikidō)・কোদাই(Kōdai)・রেনকোজি(Renkōji)。
- **地域・県の記事の多くは、長い母音を、独立母音字を重ねて書く**: চুউবু(Chūbu = চু+উ)・চুউগোকু(Chūgoku)・কান্তোও(Kantō = তো+ও)・তোওহোকু(Tōhoku)・কোওচি(Kōchi = কো+ও)・ওওইতা(Ōita = ও+ও+ইতা)。
  語数は 6 で、書かない語の約 11 に対して少なくない。**同じ編集者の一貫した転写方式とみられる**が、同じ県の記事でも হিয়োগো(Hyōgo)は重ねない。
- **কৌবে(Kōbe)は ō を二重母音字 ৌ で書く**、**কিউশু(Kyūshū)は kyū を কিউ(ki+u)で書く**など、独自の書き方もある。
- 重ね書きは、ベンガル語話者にとって「長い」という印として通じる可能性があるが、**通じるかは話者の確認が要る**。

### 読み取れること

1. **日本語→ヒンディー語表記で、長さを書き分ける手段は既存の慣習に無い**(ō・ē は同形、ū・ī も揺れる)。ja-hi が長音マーカーを全母音に付ける(ja-hi-spec §4)のは、既存の綴りと衝突せず、足りない情報を補う方針として妥当。
2. **ベンガル語には、独立母音字の重ね書き(তোও・চুউ)という、既存の(一部の)慣習がある**。ja-bn の長音は、右肩マーカー(ja-hi と共通)と、重ね書きの2案がある。重ね書きは新しい記号が要らず字幕にも収まるが、「長い」の印として一貫して使われているわけではない。ja-bn の設計書で決める。
3. **avagraha(ऽ)を長さの印に使う例(ओऽनो)がヒンディー語版にある**。1 例のみで、慣習とは言えない。
