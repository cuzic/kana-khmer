## 1. 目的と範囲

日本を旅行するクメール語話者(ADR-0010 の学習者像)が、日本語の音をクメール文字で読めるようにする補助表記の**生成規則と対応表**を定める。
出力は発音ではなくクメール語の正書法(系列の選択と慣習的綴り)なので、`khmer-kana` の逆変換ではなく別の表になる(ADR-0010 コンテキスト)。

| 範囲内 | 範囲外 |
|---|---|
| 基本46音(あ〜ん、を を含む) | 外来語音(ティ・ファ・ヴ・ウィ・ウェ・ウォ 等。ADR-0017 の仮表にある w の渡り音対応は未検証で本書の表に入れない) |
| 濁音・半濁音(が・ざ・だ・ば行、ぱ行。ぢ・づ を含む) | 漢字、かな綴りから発音への変換(ADR-0010 決定2) |
| 拗音(き・ぎ・し・じ・ち・に・ひ・び・ぴ・み・り の ゃ・ゅ・ょ) | アクセント線の描画と符号化(ADR-0010 決定6。§3.3) |
| 撥音「ん」、促音「っ」、長音「ー」の規則。連母音 あい の最小規則(§6.4) | UI、音声、フォント生成 |

表記は音声と併用する(ADR-0010 決定4)。本書の表記だけで正しい発音が伝わるとは主張しない。

## 2. 入力形式

ADR-0010 決定2のとおり、入力は**発音を確定した日本語**とする。

```
utterance = phrase { " " phrase }          ; 空白はアクセント句または語の区切り
phrase    = mora { mora }
mora      = kana | kana small | "ッ" | "ン" | "ー"
kana      = ア〜ン のうち ッ ン ー を除く1文字(濁音・半濁音を含む。ヴ は範囲外)
small     = "ャ" | "ュ" | "ョ"               ; 小書きの ァィゥェォ は範囲外
```

- 長音は `ー`(おう・おお・えい・ええ は データ側で オー・エー と書く)、促音は `ッ`、撥音は `ン`、助詞は発音どおり(は→ワ、へ→エ、を→オ)。
- 撥音の同化(後続音による ン の書き分け)は §6.1 のとおり**行わない**(多数派が ន 固定のため)。データは「ン」とだけ書く。
- アクセント(核の位置、語単位)は任意の付加情報で、本書は扱わない(§3.3)。
- 生成器はクメール文字を発音から規則でビルド時に生成する(ADR-0010 決定3)。規則で表せない語だけデータ側に override を持つ。

## 3. 表記の層

ADR-0010 決定3・6の表記の思想を、3つの層として定義する。

### 3.1 基底文字

クメール文字。子音字、下付き子音(coeng)、母音記号、末子音、◌៉ ◌៊ を含む。**詳細とライトで同じ**(ADR-0010 決定3)。
系列(a系・o系)の選択、母音記号、末子音は §4・§5・§6 の規則と対応表で決める。
文字の並びは、**coeng+子音の後に ◌៉ ◌៊ を置く**(例 ហ្ស៊ូ = U+17A0 U+17D2 U+179F U+17CA U+17BC)。借用語調査の表にある ហ៊្វុ のように ◌៊ を coeng の前に置くと、km-IPA は別の読みにする(実測: ហ៊្វូ /hʋuː/、ហ្វ៊ូ /fuː/)。

### 3.2 右肩 IPA

クメール文字に無い音を、書記音節の末尾に上付き文字(と長音記号)で足す。**本書が採る記号は次の2つだけ**。

| 記号 | 意味 | Unicode | 詳細 | ライト(暫定) | 根拠 |
|---|---|---|---|---|---|
| `ː` | 長音(ー) | U+02D0 MODIFIER LETTER TRIANGULAR COLON | 全ての長音に付ける | 残す | ADR-0017: 長短を潰すと共通語 14.4%・全体 8.5% が新たに同綴りになる。借用語では長音がほぼ書き分けられず(§7)、独自の記号になる(ADR-0010 決定3) |
| `ᶴ` | ʃ(し・しゃ・しゅ・しょ) | U+1DB4 MODIFIER LETTER SMALL ESH | し行の全部に付ける | しゃ・しゅ・しょ に残し、**し だけ落とす** | ADR-0017: ʃ を潰すと共通語 2.5%・全体 1.4%(サ/シャ、ス/シュ、ソ/ショ)。し には同綴りになる相手が無いので落としても新たな衝突は出ない(**新表での再測定前の暫定**) |

検討して**採らなかった**右肩記号:

| 記号 | 理由 |
|---|---|
| `ᶾ`(ʒ。仮表が じ・じゃ 系に使用) | じ=ជ と ち=ឈ、じゃ=ច と ちゃ=ឆ を基底の有気・無気で書き分けるので不要(§7)。ADR-0017 の「チ/ジ 2.0%」の測定は仮表(ち・じ が同じ ជ)基準なので、新表で再測定する |
| `ᶲ`(ɸ。ふ) | 借用語の慣習的綴り ហ្វ で足りる音として基底のみとする(ADR-0010 決定3)。ふ と他の音の対立は無く、機能負担量は 0 |
| ç(ひ) | 上付き文字が Unicode に無い(机上確認 §9)。基底の ហ៊ី だけで書く |
| `ɾ`(ら行) | U+107A9 で、新しい文字なので古い環境で欠ける恐れがある(ADR-0010、ADR-0016)。ら行に r と ɾ の対立は無く、付ける機能上の利点も無いので付けない |

規約(ADR-0010 決定3が「設計書で規約にする」とした点):

- 右肩記号(`ᶴ`)と長音記号(`ː`)は**書記音節(基底+末子音)の末尾にしか置けない**。頭子音・母音・末子音のどれを指すかは曖昧になる。本書の2記号は、`ː` は直前のモーラの母音、`ᶴ` は音節の頭子音を指すと決める。ん・っ の末子音が同じ書記音節に入るときの並びは §6.3 で未決とした。
- **長音記号 `ː`(U+02D0)は右肩に上げず、基底の右に、基線に通常サイズで置く**(ユーザー判断、2026-09-28。当初は右肩としていたが変更)。U+02D0 は上付きの字形を持たず、通常は基線に置く三角のコロンなので、上付き文字を探す必要が無い。右肩記号は `ᶴ` などの音色の印に限る。`ː` はクメール文字と同じ行の基線に並ぶため、クメール文字の書記音節との並び(直前の母音記号や末子音との間隔、行分割・nowrap)は、**字形と位置の実機確認(`glyph-check`)が要る**(未確認)。
- 右肩のラテン文字がクメール文字の辞書による行分割を乱すので、書記音節+右肩は `white-space: nowrap` で包む(ADR-0010 決定3)。
- 上付き文字も NFKC/NFKD を適用しない(CLAUDE.md)。
- km-IPA は右肩記号を読めない。§9 の読み戻しは基底だけを対象にし、右肩は別の検査にする。

### 3.3 アクセント線

ADR-0010 決定6のとおり、文字の上の線で表す。**符号化・描画・ライトに残すかは本書では決めない**(別途)。本書の入力形式(§2)は、アクセント情報を付けられるようにしておくだけにとどめる。

### 3.4 詳細とライト

- 詳細 = 基底 + 長音記号 `ː`(右に置く)+ 右肩(`ᶴ`)。
- ライト = 詳細から右肩の span を機能負担量で選んで捨てたもの(ADR-0002 方式・ADR-0006)。基底は同じで、差は記号の**追加**だけ。
- 現時点でライトに落とすのは **し の `ᶴ` だけ**。それ以外は詳細と同じ文字列になる(この点は ADR-0006 が挙げた負の影響と同じ)。新表で衝突率を測り直してから確定する(§8)。

## 4. 母音の割り当て

### 4.1 規則

借用語調査の実例(197 行)を、モーラとクメール文字の音節に機械で対応づけて数え(§11)、次の規則を立てた。**規則は実例の多数派に従う**(ユーザー判断)。

| 規則 | 内容 |
|---|---|
| 規則1(子音字) | 行の子音字は、借用語の実例で多数派の字にする。少数派は採らない(が行 ហ្គ、ざ行 ហ្ស、ぱ行 ប៉、拗音 ្យ、ら行 រ など。§7) |
| 規則2(系列) | 母音に合わせて a系形・o系形を選ぶ。あ・え・お は a系形、い・う は o系形。o系の共鳴音は ◌៉ で a系にし(ម៉ យ៉ រ៉ វ៉ ប៉)、a系の ស ហ ប は ◌៊ で o系にする(ស៊ ហ៊ ប៊)。な行は ណ(a系。な・ね・の)と ន(o系。に・ぬ)。実例と一致し、机上確認の系列表とも整合する |
| 規則3(母音記号) | 段ごとの既定は**母音全体の多数派**: あ ា、い ី、う ូ、え េ、お ូ(§4.2)。ただし、そのセルの実例が3語以上あり、6割以上が同じ別の記号なら、セルの多数派に従う(該当: ほ ុ、る ុ、ご ុ、じょ ុ、つ ឹ) |
| 規則4(実例なし・割れ) | 実例が無い、または割れているセルは、規則1〜3で作った候補を置き、状態を「要決定」または「根拠弱い」にする。推測の綴りを確認済みとは書かない |
| 規則5(衝突回避) | 規則1〜3の結果が別の音と同じ綴りになる場合は、実例のある別形を採る(ず ≠ ぞ、ち ≠ じ、ちゃ ≠ じゃ、ぎゅ ≠ ぎょ)。§10 の変更に列挙 |

実例で規則から外れる**例外(多数派をそのまま採った)**は、ふ(a系 ហ្វ + ូ)、め(o系 ម + េ)、ガ行(ហ្គ 全段。系列が資料で食い違うため要決定)。読み戻しが日本語から外れるので、対応表で ⚠ を付けた。

### 4.2 母音記号の実例集計

借用語調査を対応づけた**拍数**(語の重複を除いていない)。長音は借用語調査の モーラ 欄で `:` が付いたもの。

| 母音 | 短い拍 | 長い拍 |
|---|---|---|
| あ | ា 198、(記号なし 12) | ា 1 |
| い | ី 103、ិ 36 | ី 2 |
| う | ូ 36、ឹ 21、ុ 18、ឺ 2 | ូ 6、ឺ 5 |
| え | េ 29、ិ 14、ា 1 | េ 4 |
| お | ូ 56、ុ 50、ោ 1 | ូ 36、ុ 1 |

- あ・い・え は既定の記号(ា ី េ)が明確な多数派(94%、74%、66%)。
- **お・う は割れる**。お は短い拍で ូ 56 : ុ 50 の同数、長い拍では ូ 36 : ុ 1。う は ូ 36 : ឹ 21 : ុ 18 で、過半の記号が無い。母音全体の最頻の記号を既定にしたが(お は短長合計で ូ 92 : ុ 51、う は ូ 42)、根拠は強くない。
- 長い お段が ូ にほぼ固定なので、**長さを ː で書き、基底は短長共通の ូ にする**方針(§4.3)と矛盾しない。

読み戻し(km-IPA 実測。子音字 ក=a系、គ=o系。`ហ្ក`/`ហ្គ` は補助子音で、Module はそれぞれ a系・o系として読む):

| 子音字 | ា | ិ | ី | ឹ | ុ | ូ | េ | ោ |
|---|---|---|---|---|---|---|---|---|
| ក(a系) | kaː | keʔ | kəj | kə | koʔ | kou | keː | kao |
| គ(o系) | kiə | kiʔ | kiː | kɨ | kuʔ | kuː | kei | koː |
| ហ្ក | ɡaː | ɡeʔ | ɡəj | ɡə | ɡoʔ | ɡou | ɡeː | ɡao |
| ហ្គ | ɡiə | ɡiʔ | ɡiː | ɡɨ | ɡuʔ | ɡuː | ɡei | ɡoː |

採用した組み合わせの読み戻しは次のとおり。

| かな | 系列と記号 | か行の例 | 読み戻し |
|---|---|---|---|
| あ | a系+ា | កា | /kaː/ |
| い | o系+ី | គី | /kiː/ |
| う | o系+ូ | គូ | /kuː/ |
| え | a系+េ | កេ | /keː/ |
| お | a系+ូ | កូ | /kou/(a系の ◌ូ は二重母音 [ou]。日本語の [o] の近似) |

**お段の読み戻しはすべて `ou`**(こ /kou/、と /tou/、の /nou/、も /mou/、よ /jou/、ろ /rou/、ど /ɗou/ など)で、日本語の単母音 [o] からはやや外れる。借用語の実例の多数派に従った結果で、対応表では個別に ⚠ を付けない。
o系の ◌ោ /koː/ は単母音だが、実例がほとんど無い(1 拍)ので既定にしていない。読みの近さを優先する場合の代替候補である(§8)。

### 4.3 長短をどう書くか

ADR-0010 のコンテキストが示すとおり、クメール文字は母音の長短を必ず書き分ける。日本語の短い開音節(か)を長い開音節(កា)で書くと、長音(かー)との区別が潰れる。選択肢は2つある。

- **案A(採用)**: 基底は短長共通の**長母音記号**(ា ី ូ េ)にし、長音は右に置く `ː` で示す。借用語の実例が ា ី ូ を長短に関係なく使う慣習と一致する(ユーザー判断: 長音は右肩の記号。借用語ではほぼ書き分けられない)。◌ិ が末子音の前で母音が変わる問題も避けられる(§6.5)。**代償**: km-IPA(クメール語話者)の読みは短長どちらも長母音になり、日本語の短母音とは長さがずれる。`ː` の有無はクメール語の読みでは区別されない。
- **案B(不採用)**: 短い拍は短母音記号(ៈ ិ ុ)、長い拍は長母音記号(ា ី ូ)にする(ADR-0017 の仮表の方式)。長さがクメール語の読みでも区別される。**代償**: ◌ិ が末子音の前で別の母音に変わる(§6.5)。◌ៈ ◌ិ ◌ុ は終子音なしで声門閉鎖を伴う(kaʔ、kiʔ、kuʔ)。借用語の実例は短い拍でも長母音記号が多い(あ ា 198/210 拍)ので、実例の多数派と食い違う。

案A で進めるが、**クメール語話者が長母音を日本語の短音として読み替えられるか**は文献では確かめられない。母語話者の確認が要る(§8)。

## 5. 対応表

### 5.1 凡例

- **詳細**は基底+右肩、**ライト**は §3.4 のとおり。**長音**は詳細・ライトとも、表の綴りの直後に `ː` を足す(例 とう → តូː)。
- **km-IPA 読み戻し**は、`{{km-IPA|<基底の綴り>}}` を英語版 Wiktionary の API(`action=expandtemplates&prop=wikitext`)で実行した標準クメール語の IPA(2026-09-28 実測、Module:km-pron の機械出力)。話者の実音ではない。右肩記号は読まれない。子音の ɓ ɗ(ば・だ行)、r(ら行)、ʋ(わ)、有気(ち・か の異形)などの音価差は右肩に回さない(機能負担量が無いため)ので、読み戻しの差として現れるが行ごとには印を付けない。
- **⚠** は読み戻しが日本語の音から大きく外れる行(母音が別の音、有声性が消える、系列が資料で食い違う)。**△** は近似(じ の /c/ は無声で、日本語の [dʑ] と有声性が違う)。
- **根拠**の「N/M語」は、その拍に対応づけられた M 語(借用語調査の日本語欄が異なる語の数)のうち N 語がその綴り。`#` は借用語調査の第2節の行番号。同一記事の語や同じ語の異綴りを含むので、独立した実例の数ではない(§11)。
- **状態**:
  - **確認済み**: 採用形が実例の過半で3語以上(または複数の独立出典で一致する定着語)に現れ、読み戻しが日本語の音に近い。**話者の確認ではない。**
  - **根拠弱い**: 実例はあるが、割れている・2語以下・かな表(km-wp の ហ៊ីរ៉ាហ្កាណា/កាតាកាណា。1資料)だけ・読み戻しに問題がある、のどれか。
  - **要決定**: 実例が無い、または資料が食い違う。候補を置いてあるだけで、決まっていない。

### 5.4 拗音

拗音は「子音字+្យ+母音記号」の型が実例(東京 តូក្យូ、九州 ឃ្យូ…、琉球 រ្យូ…)で一貫している。ただし、33行のうち実例があるのは 8行(きゅ・きょ・しゅ・しょ・じゅ・じょ・ちゃ・りゅ)だけで、**25行に実例が無い**(うち 7行はかな表に候補がある)。実例のある行のうち割れているものと、かな表の候補だけで決めた行は根拠弱い、それ以外は要決定とした。
しゃ・しゅ・しょ は、基底に さ行と同じ字を使い ᶴ を足す(ADR-0017 の暫定方針。実例2語以上が割れるため要決定)。じゃ行は ច(a系)・ជ(o系)、ちゃ行は ឆ(a系)・ឈ(o系)で、有気・無気で書き分ける(§7)。
ば・ぱ行の拗音(びゃ・びゅ・びょ・ぴゃ・ぴゅ・ぴょ)は、km-IPA が「p の後の j の前で有気化する」規則(Module の `fittest`)で /pʰj/ に読み、**び と ぴ の拗音が読み戻しで同音になる**(綴りは ប្យ と ប៉្យ で違う)。ぴゃ 以外の行にも ⚠ を付けた。

## 6. 撥音・促音・長音、連母音

### 6.1 撥音「ん」

**既定は末子音 ន 固定**(ユーザー判断: 多数派。後続音で ម ង に書き分けない)。

- 借用語調査を対応づけた範囲で、末子音として現れた ん は ន 28(ន់ を含む)、ង 5、ម 1。語末は ន 14/14。ង 5 のうち 3 はホンダ系(#123,124,179)で、残りは 日本語(#17)と 音読み(#40)。ម は 神武 だけ。ំ は ガンバ・ちゃん・さん で 3(集計外で確認)。
- 後続音で ម ង に同化する規則(ADR-0010 決定2が生成器に持たせるとした案)は、**多数派ではない**ので既定にしない。実行するプロファイル(方言プロファイル、ADR-0010 決定3)としては残せる。読み戻し(実測): សាម-ប៉ូ /saːm.pou/、សាន-ប៉ូ /saːn.pou/、ហុង-ដា /hoŋ.ˈɗaː/、ហុន-ដា /hon.ˈɗaː/。どちらも別の語として読める。
- ◌ំ(ニクヒット)は音節全体の母音が変わる(ា+ំ = /am/、ហ្គាំ = /ɡŏəm/)ので使わない(机上確認 §5)。
- 語頭・単独の ん と、語末の「ンッ」等の感動詞: 実例なし。**要決定**。

読み戻し(実測。基底の母音は変わらない):

|---|---|---|
| かん | កាន | /kaːn/ |
| きん | គីន | /kiːn/ |
| すん | ស៊ូន | /suːn/ |
| けん | កេន | /keːn/ |
| こん | កូន | /koun/ |

### 6.2 促音「っ」

ADR-0017 の方針どおり、**右肩にせず、末子音の基底文字で書く**。直前の音節に、次の子音に対応する末子音を足す(借用語調査の促音の型(b): ហុកកៃដូ = ហុក+កៃដូ。実例は同形が (b) 6 対 バントック付きの型 (a) 4)。

| 次の子音 | 末子音 | 例 | 読み戻し |
|---|---|---|---|
| t d ts ch j s sh z n h r など | ត | きって → គីត-តេ | /kiːt.ˈteː/(実測) |
| p b | ប | いっぱい → អ៊ីប-ប៉ា-ប៉ៃ | /ʔiːp.paː.paj/(実測) |
| k g | ក | こっかい → កូក-កៃ | /kouk.ˈkaj/(実測) |

- 実測: កាត /kaːt/、កាប /kaːp/、គីត /kiːt/、គីប /kiːp/、គីក /kiːk/、ស៊ូក /suːk/、កូក /kouk/、កេក /keːk/、កាត-តេ /kaːt.ˈteː/(かって)、គីត-តេ /kiːt.ˈteː/(きって)。
- **問題: ា の直後の ក は声門閉鎖になる**(កាក /kaːʔ/、កក /kɑːʔ/、កាក់ /kaʔ/)。あ段+っ+か行(あっか)で k が消える。他の母音(ី ូ េ)の後では /k/ のまま。**要決定**(候補: 声門閉鎖のまま許容する、バントック付きの កាក់ に頼る、ក以外にする)。
- バントック(◌់)は使わない。គីត់ のように ី と組むと km-IPA が読めない(実測)。កាត់ /kat/ は母音を短くするので長母音記号の基底(§4.3 案A)と合わない。
- 語末の ッ(あっ、えっ 等): 実例なし。**要決定**。
- 促音を書かない型(借用語調査 型(c))と、同じ字を coeng で重ねる型は使わない(重ね書きが重子音として読まれる証拠が無い。ADR-0010)。

### 6.3 長音「ー」

- **全ての長音に、直前のモーラの表記の直後へ `ː` を足す**(ユーザー判断)。基底の母音記号は短長共通(§4.3)。例: 東京 → តូːក្យូː、ラーメン → រ៉ាːមេន。
- 根拠: 借用語調査の長音は専用の字を持たず、ラーメン រ៉ាមេន(ា)、ソニー សូនី、すもう ស៊ូម៉ូ(ម៉ូ)のようにほぼ書き分けられない。長い お段は ូ が 36 : 1。したがって既存の慣習と衝突せず、右肩の記号は独自になる。
- **未決**: ん・っ の末子音が同じ書記音節に入るとき(らー+ん、こー+っ)、`ː` を末子音の前後どちらに置くか。末子音の後ろに置くと、`ː` が末子音の長さに見える。書記音節の末尾にしか置けない制約(§3.2)との関係で決める(§8)。

### 6.4 連母音 あい

- **あい は ៃ 1文字で書く**(あ+い を別々の音節にしない)。借用語調査のあい系 8語(9行: #10,11,15,58,82,86,102,103,107。#10 と #11 は同じ語)は全て ៃ。
- 実測: កៃ /kaj/、សៃ /saj/、ម៉ៃ /maj/、រ៉ៃ /raj/、ហៃ /haj/、ណៃ /naj/、ដៃ /ɗaj/、អៃ /ʔaj/。
- 状態: あい は**確認済み**(8語で全て ៃ、読み戻しも /aj/。§5 の104行には数えていない)。うい・おい・えい・おう は、別の音節に分けて書く実例が多い(えい は せい=សេ と សេអ៊ី が併存)ので、本書では「各モーラを別に書く」とし、専用の規則は持たない(**要決定**)。

### 6.5 ◌ិ ◌ុ が終子音の前で母音が変わる問題への対処

ADR-0010 は「◌ិ は [ə]/[ɨ] に、◌ុ は [o]/[u] に変わる」と書いた。実測では**変わるのは ◌ិ だけ**で、◌ុ と ◌ឹ は終子音なしの読み(声門閉鎖を除く)と同じ母音のまま。

| 綴り | 終子音なし | 終子音あり |
|---|---|---|
| គិ → គិន | /kiʔ/ | /kɨn/(**i が ɨ に変わる**) |
| កិ → កិន | /keʔ/ | /kən/(**e が ə に変わる**) |
| ឈិ → ឈិន | /cʰiʔ/ | /cʰɨn/(**変わる**) |
| គុ → គុន | /kuʔ/ | /kun/(変わらない) |
| កុ → កុន | /koʔ/ | /kon/(変わらない) |
| គឹ → គឹន | /kɨ/ | /kɨn/(変わらない) |

対処案(本書の採用):

1. **基底に長母音記号を使う**(§4.3 案A)。គីន /kiːn/、ឈីន /cʰiːn/ のように、ん・っ の前でも母音は変わらない(§6.1、§6.2 の実測)。
2. ◌ុ・◌ឹ を採るセル(ほ・る・ご・じょ・つ)は、終子音の前でも母音が変わらないので問題は出ない(ហុន /hon/、រុន /run/、ត្ស៊ឹន /tsɨn/)。ただし ご は ហ្គ の系列の問題(§5.3)が別に残る。
3. **◌ិ は基底に使わない**。え段を ◌ិ で書く実例(14 拍。え・て・ね・め・れ・べ 等)は採らない。え段は េ で、ん・っ が付いても /eː/ のまま(កេន /keːn/)。

## 9. 読み戻し検証の方法

ADR-0010 決定7(a)を、次のように具体化する。**本書の読み戻し値は、下の(1)を候補の綴りごとに直接実行しただけで、(2)以降の自動テストは未作成。**

1. **実測(本書で実施)**: 候補の綴りごとに `https://en.wiktionary.org/w/api.php?action=expandtemplates&prop=wikitext&format=json&text={{km-IPA|<綴り>}}` を呼び、出力の `/…/`(標準クメール語の IPA)を読む。単語は音節をハイフンで区切って渡す(区切らないと Module が音節境界を誤る。借用語調査 §3 冒頭)。約800件(子音字約50種×母音記号12種の格子、候補の綴り、末子音付き、語例)を実行した。WebFetch ではなく同じ API を Node の `fetch` で直接叩いた(件数が多いため)。結果は作業用のキャッシュ(リポジトリ外)に置いた。
2. **読み戻し表の作成(未作成)**: 生成器が出しうる綴りの閉じた集合(子音字×下付き×◌៉◌៊×母音記号 ា ី ូ េ ុ ឹ ៃ×末子音 ន ត ប ក ង ម)に限り、`系列×母音記号×末子音 → 母音` の表を作る。**生成側の対応表は参照しない**。データ源は Wiktionary のクメール語見出し語:
   1. `Category:Khmer lemmas`(または `{{km-IPA}}` を持つページ)を API で列挙する。
   2. 各見出し語の `{{km-IPA|…}}`(ページ自身の引数)を展開して IPA を得る。
   3. 見出し語を書記音節に分け、上の閉じた集合に当てはまる1音節だけを残す。
   4. `(子音字の系列, 母音記号, 末子音)` ごとに IPA を集計し、多数派を表にする。割れる組(ហ្គ の系列、o系 ◌េ の /eː/ と /ei/)は「既知の食い違い」として別に持つ。
3. **自動テスト(未作成)**: (a)対応表の全行を読み戻し表で読み、期待する日本語の母音・子音の類(§5.1 の許容差を含む)と比べる。(b)`phrases.yaml` の発音から生成した全語を、ハイフン区切りで読み戻す。(c)既知の食い違いの組は、テストを「不一致を許す」印付きで固定する。
4. **二次確認**: 系列×母音記号の表は英語版 Wikipedia "Khmer script"(Huffman 由来)とも突き合わせ、食い違いを本書に記録する(今回、机上確認と借用語調査に記録済み)。
5. **範囲外**: 長音記号・右肩記号(`ː` `ᶴ`)は km-IPA が読まないので、別に「基底を除いた残りが `ː` と `ᶴ` だけか」を検査する。

**Module の出力の限界**: Module:km-pron は UNESCO の発音辞典を典拠とし、実音ではない。ស្ស を /ss/ と読む、ហ្គ を o系として読む(Wiktionary 編集者は ហ្កា と入力して補正している)、ប を ្យ の前で有気化する、など、日本語の音写に使う綴りに不利な読みがある。読み戻しが一致しても、話者がその綴りを日本語の音として読めることの証明にはならない。
(借用語調査 §3-1 は ហ្ស៊ を Module がエラーにすると記していたが、今回は ហ្ស៊ូ /zuː/ などが読めた。coeng の後に ◌៊ を置いた並びで実行している。エラーになったのは ច៊ូ で、ច は ◌៊ を取れない。前者の食い違いの原因は未確認)

## 11. 実例の集計方法と限界

- 借用語調査の第2節の表 197行のうち、日本語の音写でない 6 行(日本・NHK・JICA・ミネベア・日経・国際協力機構)を除く 191 行を、モーラ欄とクメール文字の音節に**機械で対応づけた**(モーラ列を、子音字で始まる音節の列に順に当てる。ん・っ は末子音の音節を1つ取るか飛ばす。あい は ៃ に合流。人名の姓名順の入れ替えを試す)。175 行が対応づいた。残り 16行(長文、ក់ 付きの助詞、姓名の並びが合わない行など)は集計に入っていない。
- 対応づけには、子音字の許容表(例 か行の拍は ក ខ គ ឃ で始まる音節だけ)を使い、明らかな誤対応は落としたが、**誤対応が残る可能性がある**。数は `N/M語` の形で示し、行ごとの根拠欄に借用語調査の行番号を書いたので、原表で追える。
- `語`は借用語調査の日本語欄が異なる値の数。同じ語の異綴り(安倍晋三 4行)は1語に数えた。ただし、同一記事の語(少年・少女・魔法少女の しょ・じょ)は独立した実例ではない。
- **km-wp(クメール語版 Wikipedia)は個々の編集者の実践**で、記事間で同じ語が違う綴りになる。Wiktionary の見出し語(9語)は質が高いが少ない。実例は話者一般の使用頻度ではない(借用語調査 §5-4)。
- 借用語調査の集計・アラインメントに使った作業用スクリプトはリポジトリに無い(§8 の #13)。
