# ADR-0025: ヒンディー語・ベンガル語話者向けに、日本語→デーヴァナーガリー/ベンガル文字表記(ja-hi・ja-bn)を ja-khmer と同じ枠組みで設計する

## コンテキスト
ADR-0010 は日本語→クメール文字、ADR-0018・0019 は日本語→ハングルの表記を置いた。ヒンディー語話者・ベンガル語話者向けにも同じ枠組みが使えるかを検討した
(文字の音価に関する記述は一般知識で、文献未照合)。

- **構造が近い**: デーヴァナーガリー文字とベンガル文字はどちらもブラーフミー系のアブギダで、子音字+母音記号+ヴィラーマ(母音なしの印)+結合字という体系を
  クメール文字と共有する。ハングルよりも ja-khmer に近く、「かな1拍 → 子音字+母音記号」の対応表を設計書から生成する方式(ADR-0023)がそのまま使える。
- **日本語側の情報は共通**: ピッチアクセントのデータ(ADR-0021 の n 値)、拍への分割、詳細/ライトの2段は言語に依らない。
- **文字・言語ごとに決め直す点**(いずれも初期案の段階で、設計書で確定する):
  - 長音: ヒンディー語は母音の長短を区別し長母音字がある。ベンガル語は長短を区別しないため、長音を明示する記法が要る(ADR-0019 の右肩記号と同じ問題)。
  - 「う」[ɯ] は唇を丸めない音で、उ/উ(丸める)とずれる。「お」は ベンガル語の অ [ɔ] ではなく ও [o] に当てる。
  - し・す・せ・ざ行: ベンガル語は স・শ・ষ が ほぼ /ʃ/ に読みが合流しうるが、ベンガル語版 Wikipedia の記事名は s を স、sh を শ で書き分けていた(s 20 : 0、sh 16 : 0)ので、綴りの上では区別できる。ヒンディー語は स/श の区別と ज़(nukta)がある。
  - た行・だ行: 日本語の t/d は歯茎寄りで、歯音の त/द 系が自然、というのが初期案だった。ヒンディー語版 Wikipedia の綴りを数えると、t は歯音(32 : 11)、d はそり舌(ड 13 : द 6)が多数派で、
    設計書 `docs/ja-hi-spec.md` §7 は、いったん t=त・d=ड を採ったが、ユーザーが日本語の d の音の近さを優先して **t=त・d=द(歯音)に戻した**(2026-09-29)。d のそり舌はヒンディー語版に固有の多数派で、マラーティー語(歯音 6 : 2)・ベンガル語(歯音 9 : 2)は t・d とも歯音が多い。
    ベンガル語版は ু ি だけを使い長短が綴りに出ない(短い u で ূ は 0)。詳細は [調査メモ](../research/2026-09-29-ja-loanwords-in-brahmic-wikipedia.md)。
  - ふ [ɸ]: फ/ফ は [pʰ] にも読まれうる。
  - ん・っ: ヴィラーマと結合字で表せるが、フォントでの結合字の描画確認が要る。
  - **ヘッドライン(शिरोरेखा/মাত্রা)**: 両文字は文字の上端に横線を持つ。ADR-0021 の「拍の上に引く上線(H のみ)」は、この線と重なるか区別が付かなくなる。
    クメール文字にはこの線が無いので、ADR-0021 はそのままでは使えない。
- **日本語からの借用語の実態(2026-09-29 調査)**: en.wiktionary の「Terms derived from Japanese」カテゴリの語数は、ヒンディー語 93・ベンガル語 7・クメール語 9。
  ヒンディー語は大半が地名(ホッカイドウ・ヒロシマ等)で、一般語は सुशी(寿司)・जूडो(柔道)・कराटे(空手)・हाइकु(俳句)・मांगा(漫画)・ऐनिमे(アニメ)・
  सुनामी(津波)・टोफ़ू(豆腐)・कांजि(漢字)・इमोजी(絵文字)・रिक्शा(人力車)など。ベンガル語は অ্যানিমে・মাঙ্গা・সুনামি・জুজুৎসু・রিকশা・হাশি(箸)など。
  クメール語は ខារ៉ាអូខេ(カラオケ)・គីម៉ូណូ(着物)・ស៊ូស៊ី(寿司)・រ៉ាមេន(ラーメン)・អានីមេ(アニメ)など。**Wiktionary の編集者が拾った範囲で、実際の借用語の網羅ではない**。
  英語経由の語(सुनामी など)があり、日本語から直接入った語は地名・固有名詞を除くと少ないとみられる(未検証)。হাসনাহেনা(蓮の花 hasu no hana の変形と書かれている)の由来は未裏取り。
  綴りには次のゆれがある: 長音は ो・ू で表す(होक्काइदो・होन्शू)、ん は ं と न् の両方(कांजि・होन्शू)、っ は子音の重ね(होक्काइदो)、つ は त्सु、ふ は फ़、ざ行は ज़、
  東京は टोक्यो(そり舌)と तोक्यो(歯音)の両方。**定まった標準綴りは無く、初期案の「t/d は歯音」も、実際には定まっていない**。
- 学習コースの単位は ADR-0020(言語の組み合わせ別)、共通基盤を切り出すかは ADR-0023(当面切り出さない)が決めている。

## 決定
1. **ja-hi(ヒンディー語話者向け、デーヴァナーガリー文字)と ja-bn(ベンガル語話者向け、ベンガル文字)を、ja-khmer と同じ枠組み**
   (かな発音 → 文字の対応表 → 詳細/ライトの2段、表は設計書から生成。補助記号は ja-hi では長音の `ऽ` だけで、ja-khmer の右肩記号は使わない。[ADR-0027](0027-ja-hi-long-vowel-avagraha.md))で設計する。表記の設計書は `docs/ja-hi-spec.md`・`docs/ja-bn-spec.md`
   として別に起こし、本 ADR には決定の経緯だけを残す。学習コースは ADR-0020 に従い `courses/ja-hi`・`courses/ja-bn`。
2. **着手順は ja-hi が先、ja-bn は後**。ヒンディー語は長音・s/sh の区別が文字で書け、決める点が少ない。ベンガル語は長音・し・お の3点の追加設計が要る。
3. **パッケージは `packages/ja-hi` を先に作り、共通化はしない**。ADR-0023 の「当面切り出さない」に従う。ja-bn の着手時に、ja-khmer・ja-hi・ja-bn の3つが揃った時点で、
   ブラーフミー系に共通する処理(子音字+母音記号、ヴィラーマ、結合字による ん・っ の書き分け)が実際に重なるかを見て、共通の中核を切り出すかを新しい ADR で決める。
4. **ADR-0021(ピッチアクセントの上線)は ja-hi・ja-bn には未適用とする**。ヘッドラインとの衝突を避ける記法(ヘッドラインの上に離して引く、下線にする、
   背景色で示す、等)は `glyph-check` の実機確認で決め、決まったら新しい ADR を起こす。それまで ja-hi・ja-bn の表示にはアクセントの線を出さない。
5. **日本語からの借用語は、導入用の語と表の試験データにだけ使い、表記の正としない**。sushi・anime・manga・tsunami・karaoke・judo・karate・emoji などは、
   学習者が既に知っている語なので、「読める」と実感させる導入(例: 各コースの最初のシーン)に使う。既存の綴りは、対応表の出力と比べる**参照データ**とし、
   ゆれのある点(t/d、ん、長音)では一致を合格条件にしない。表の決定は設計書と、母語話者の確認(未定)による。
   Wiktionary(CC BY-SA 4.0)由来の綴りを取り込むなら、ADR-0021 決定8 と同じく、そのファイルだけを分離し、出典(語ごとの項目名と取得日)を付ける。
6. **ヒンディー語とネパール語は同じデーヴァナーガリー文字なので、ネパール語向け(ja-ne)は ja-hi の表を種にする**。ただし着手は ja-hi が固まってから別に決める(本 ADR の範囲外)。

## 検討した代替案
- **ローマ字だけを見せる**: 各コースの表示要素には元からローマ字を含める(ADR-0022)が、ヒンディー語・ベンガル語話者は自国の文字で読むほうが速い、というのが
  ja-khmer と同じ前提。ローマ字は併記で残し、代替にはしない。
- **ヒンディー語の表を機械的に文字変換してベンガル語に使う**: 2つの文字はコードポイントが似た並びだが、音韻が違う(母音の長短、s/sh、o/ɔ)ので、変換では長音・し・お が崩れる。却下。
- **最初から共通の中核(ja-brahmic)を作る**: 2つ目の文字を作る前に共通部分を予測して切り出すと、ADR-0023 が避けた早すぎる抽象化になる。却下し、3つ揃った時点で判断する。
- **ja-bn を先に作る**: 人口はヒンディー語が多く、決める点も少ないので、ja-hi を先にする。
- **既存の借用語の綴りを表の正にする**: 語数が少なく(ベンガル語 7・クメール語 9)、多くは地名で英語経由のものもあり、綴りにゆれがある(t/d、ん、長音)ので、
  表の根拠にならない。参照データに留める(決定5)。
- **ADR-0021 の上線をそのまま使う**: ヘッドラインと重なる。実機の見え方を見ずに決めるのは危ういので、決定4のとおり保留。

## 結果(影響)
- 日本語→(自国文字)の表記が3つ目・4つ目の言語に広がる。表・生成・確認の作業が言語ごとに増える。
- 上記「決め直す点」は、設計書を書く中でそれぞれ決め、変更が ADR の水準(却下案がある・横断する)なら個別に ADR を起こす。
- 確認者(ヒンディー語・ベンガル語の母語話者)は未定。設計書の表はいずれも**未確認**として扱い、確認済みとは書かない。
- フォント: Noto Sans Devanagari・Noto Sans Bengali での描画を `tools/glyph-check` に加える必要がある(ADR-0004 に従い目視を正とする)。
- ja-hi・ja-bn には当面アクセントの線が出ない(決定4)。
- 借用語の参照データ(決定5)を取り込む場合は、CC BY-SA のファイルが1つ増え、帰属表示の対象になる。継承の範囲の法的判断は ADR-0021 と同じく未確認。ADR-0021 の表示は ja-khmer のみ。
