# ADR-0005: ŋ の表記を多言語共通の右肩 modifier `ᵑ` に統一する

## コンテキスト
`ŋ` の表記は当初「半濁点(`゚`)」+ 専用の変換表(`DENASAL`、`カ゚キ゚ク゚ケ゚コ゚ン゚` の6パターン置換)
だった。`゚` は `ㇷ゚`(p の半濁点)と兼用の記号だったため、ライトへの変換で「半濁点を無条件に落とす」が
使えず、ŋ だけ個別の変換表が要る歪さがあった。多言語展開の検討(2026-09-26)で、他言語の IPA
修飾文字と表記の枠組みを揃える方針が決まり、`ン+゚` のリガチャ(合字)案と、右肩の独立記号 `ᵑ`
(U+1D51)案の両方を実機(iOS/Android)で試作した。

## 決定
どちらの案も iOS/Android 実機で正しく描画されることを確認した上で、ユーザーが多言語共通化を理由に
`ᵑ` を選んだ(2026-09-27。`0131175` のコミットメッセージでは「両方とも正しく描画されたので、選択は
好みの問題」と記録されている)。`ᵑ` は既存の `cons-mod`(`ʰ ˡ ʳ`)と同じ枠の span として扱い、
専用の変換表(`DENASAL`、`kana-nasal` span 種別)は廃止する(`3fd8126`)。

## 検討した代替案
- **`ン` + `゚` のリガチャ(合字)案**: iOS/Android 実機でどちらも正しく描画されることを確認済みだったが、
  多言語共通化を優先して不採用にした。`kana-multi.woff2` からも該当グリフを削除した(150→149 グリフ)。

## 結果(影響)
新しい言語パッケージが子音+右肩記号の対立を持つ場合、専用の置換表を新設せず `cons-mod`/`vowel-mod` span +
「落とす集合」の枠組み([ADR-0002](0002-two-level-notation-via-spans.md))に乗せられる。フォント側も
`ᵑ` 用の合成グリフだけ追加すればよくなった。同じ方式を `ʔ`(子音連続先頭のみ)にも適用するかは
別の決定([ADR-0011](0011-glottal-stop-prefix-modifier.md))として分けている(配置規則・実データでの
必要性・決定日がいずれも異なるため)。
