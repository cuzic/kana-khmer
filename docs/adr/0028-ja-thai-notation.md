# ADR-0028: 日本語→タイ文字(ja-thai)は、開音節をすべて長母音で書き、長音は母音を重ねる

## コンテキスト
タイ語話者が日本語を学ぶ(旅行で使う)ための、日本語の発音(カタカナ)→ タイ文字の補助表記を作る(`packages/ja-thai`)。
調査は [docs/research/2026-09-29-ja-loanwords-in-thai-orthography.md](../research/2026-09-29-ja-loanwords-in-thai-orthography.md)、
試作と測定は `tools/ja-thai-spike/`。分かったこと:

- ราชบัณฑิตยสภา(王立学士院)の日本語音写基準(2018)がある。子音は明確な規則があるが、長短は「開音節の短母音(語末以外)も長母音」で
  書き分けず、です・ます・助詞の例がない。
- **タイ文字は綴りが声調を決める**(子音字の類・母音の長短・生/死音節・声調符号)。日本語には声調がないので、綴りが意図せず付ける声調は
  雑音になる。短母音で終わる音節(死音節)は、中子音・高子音なら低声、低子音なら高声になり、中声調にできない。
- th-pron(Wiktionary)で読み戻して測った(ko-ja の 129 語 + 官報例 58 語、755 音節): 官報どおり 63.8%、開音節の短形 18.8%、
  開音節をすべて長母音 94.2%、語末だけ短形 76.8%。

## 決定
1. **入力**は発音を確定したカタカナ(ja-hangul と同じ)。出力は官報の子音規則(語頭の k t p ch は有気字、語中は無気字、が行は語中 ง、ん は後続音で น ง ม・語末 ง、
   つ は สึ/ตสึ、し=ชิ、ふ=ฟ、ら行=ร、拗音は เ-ีย -ิว เ-ียว)を骨格にする。
2. **声調を綴りの自然さより優先する**(ユーザー判断 2026-09-29)。開音節の母音は、i・語末も含めすべて**長母音**で書く(น**ี**、มา**ซู**)。
   閉音節(ん・っ の末子音あり)は短母音記号(ั เ-็ ิ ุ、o は記号なし)。
3. **長音(ー)は、母音だけの音節を足して重ねる**(ユーザー判断 2026-09-29): オカーサン → `โอกาอาซัง`。短(1つの長母音)と長(2音節)の差が綴りに残る。
4. 語頭・語中の判定は空白で区切った語ごと。声調符号(ไม้เอก 等)は使わない。日本語のアクセントは声調とは別の層(ADR-0021 の上線)として扱い、本 ADR の範囲外。
5. 官報と学習者の実務が食い違う音(が行語中、ふ、つ、し、じ)は**官報に寄せる**(ユーザー判断 2026-09-29)。

## 検討した代替案
- **官報どおり(短い i・語末の短母音を残す)**: 中声調 63.8%。นิ=高、จิ=低、ซุ=高、ระ=高 のように、意図しない声調が付く。
- **開音節を短形(ะ ุ เ-ะ โ-ะ)で書く**: 中声調 18.8%、声門閉鎖(ʔ)も増える。
- **語末だけ短形**: 76.8%。語末の ซุ(です・ます)が高声調になる。
- **長音を書き分けない(E)**: 中声調は G と同じ 94.2% だが、おかさん/おかあさん の差が消える。母音を重ねると 94.4% を保ったまま残る。
- **日本語のアクセントをタイ語の声調で写す**: 未検証。タイ語の声調は輪郭で、日本語の高低は相対的なので、過剰な上昇・下降に読まれるおそれがある。

## 結果(影響)
- 中声調は 94.4%(755 音節中 711 → 重ねる方式で 817 音節中 771)。残りは、促音の末子音で終わる死音節と สึ で、構造上避けられない。
- 短い i も `ี` で書くので、タイ語話者は長く読む。**この読みが学習の妨げにならないかは未確認**。母音を重ねた音節は音節数が増える(`อารีงาโตโอ`)。
- **未検証**: タイ語ネイティブの確認(A・E・G の読み比べ質問票を作る予定)、実機描画(タイ文字は Noto Sans Thai で描ける見込みだが未確認)、
  です・ます の母音無声化、外来語音(ティ・ファ 等)。
- th-pron の API は数百回で 429 になる。複数テンプレートを 1 リクエストにまとめる。
