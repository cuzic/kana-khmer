# ADR-0034: 英語のカナ表記は、慣用的な日本語表現より、実際の音に近いカナを優先する

## コンテキスト
[ADR-0031](0031-en-kana-with-shoulder-ipa.md) の表記には、日本語での慣用を優先した規則が一部あった。たとえば v をヴ行にする理由は「慣用的に受け入れられているから」、語末でない dʒ + 弱い母音は慣用の `デュ`(education → エデュケイシᵊン)だった。

**ユーザーの発言(原文)**:
- 「クオーターや スイーツといった例で、一部慣用的な日本語表現を優先していた部分がありましたが、やめましょう。」
- 「クウォーター のような実際の音に近いカタカナにすることを優先して。子音だけのクは小さいク」
- 「スイーツなら スウィーツ みたいなかんじですね。スは小さいス」

## 決定
1. **慣用的な日本語の表記より、実際の音に近いカナを優先する。** 母音の前以外の子音は、これまでどおり小書きカナ(ㇰ ㇲ ㇳ ㇷ゚ ㇱ ㇺ ㇽ)で書く。
2. **`quarter` は `ㇰʰウォ…`、`sweets` は `ㇲウィーツ` のまま。** 現行の出力は、すでにこの方針に合っていた。
3. **語末でない dʒ + 弱い母音の `デュ` をやめ、語末と同じ `ヂャ` にする**(education → エヂャケイシᵊン、Japan → ヂャパン)。`kana.ts`・`kana.py` から該当の分岐を削除した。
4. **ほかの規則は、洗い出した範囲では慣用優先のものは見つからなかった。** ヴ行(v の実際の音に近い)、ツ・ヅ(破擦音)、ヂ(dʒ)、フュー(f + j)は、実際の音に合うので変えない。見つかったら、この ADR の方針で直す。

## 検討した代替案
- **デュ のまま**: 日本語の慣用(エデュケーション)には合うが、dʒ の音ではない。
- **ヂュ にする**: 弱い母音が /ʊ/ のときは近いが、CMUdict は AH0(シュワー)で出すので、シュワーに合う `ヂャ` にした(語末の シャ・チャ・ヂャ と同じ)。

## 結果(影響)
- `packages/en-prosody/test/decided.test.ts` と `golden.json` の education・Japan などが変わる。
- 洗い出しは手元の 80 語ほどの出力を目で見た範囲。ユーザーが気づいた語は、個別に指示してもらって直す。
