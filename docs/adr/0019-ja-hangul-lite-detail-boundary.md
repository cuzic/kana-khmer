# ADR-0019: 日本語→ハングル表記の記号を右肩ローマ字にそろえ、長音・促音・区切りをライト、じゃ・じょ の ʲ を詳細だけにする

## コンテキスト
日本語→ハングル表記(`tools/ja-hangul-spike/`、表は暫定)には、素のハングルで書き分けられない対立が
ある。それぞれ記号(綴りの上の印)で補う。khmer 側と同じく、詳細/ライトの2段にする(ユーザーが選択)。
[ADR-0018](0018-ja-hangul-n-boundary-marker.md) で、ん・っ の直後の区切り `·` はライトでも残すと決めた。

記号の方式は、クメール側([`docs/ja-khmer-spec.md`](../ja-khmer-spec.md) §3.2 の D8)と同じ**右肩の日本語ローマ字(上付き文字)**にそろえる(ユーザー判断 2026-09-29)。当初の案(長音は母音の重ね書き、じゃ/じょ は下付きの結合記号 U+0324)は、この判断で取り下げた。

補う対象は4つ(ADR-0017 と同じ測り方。JMdict 常用語 21,669 語、同音の語は除く、値は仮表・ネイティブ確認前):

| 記号 | 何を補うか | 潰したときの新たな衝突 | 読みの崩れ | 表記の手段 |
|---|---|---|---|---|
| 長音 | おばさん/おばあさん | 13.5% | あり | 直前の音節の右肩に母音の上付きローマ字(ᵃ ⁱ ᵘ ᵉ ᵒ)。例: 오바ᵃᵃ산。字形は (c) 重ね書き ᵃᵃ か (a) マクロン付き ᵃ̄ かを未決とし、暫定は (c)(D8 と同じ)。**フォント依存** |
| 促音 | イラシャイ/イラッシャイ | 3.1% | あり | 同位置パッチム(同上) |
| 区切り | ほんや/ほにゃ、ほんらい | 0.13% | ら行 187 語が [ㄹㄹ] に誤読 | `·`(U+00B7。Latin-1 で実質どのフォントにもある) |
| じゃ・じょ の ʲ | ざ/じゃ、ぞ/じょ | 0.54% | 衝突以外の崩れなし | 右肩の ʲ(j。ヘボン式の ja/jo の j)。ʲ は同梱の kana-support・kana-multi にある |

ライトの候補ごとの測定(全記号の詳細版との差):

| ライトの内容 | 衝突 | 読みが詳細と違う語 |
|---|---|---|
| 素のハングル | 17.91% | 44.76% |
| 長音のみ | 3.83% | 12.04% |
| 長音+促音 | 0.67% | 4.23% |
| **長音+促音+区切り** | **0.54%(118語)** | **2.31%** |
| 長音+促音+ʲ(区切りなし) | 0.13% | 1.93% |
| 全部(詳細) | 0% | 0% |

測定は右肩ローマ字に切り替える前後で同じ値だった(長音の情報量が同じため)。

「長音+促音+区切り」の 0.54% は、すべて ざ/じゃ・ぞ/じょ の衝突である。「読みが詳細と違う語」の
2.31% には、この衝突に加え、ㅈㅊ+ㅑㅛㅠ が硬口蓋化して区別されない読みの違いが含まれる。

## 決定
1. **記号は右肩の日本語ローマ字(上付き文字)で書く。** 長音は直前の音節の母音(ᵃ ⁱ ᵘ ᵉ ᵒ)を2つ重ねた右肩(暫定 (c))、じゃ・じょ は右肩の `ʲ`。順序は 子音の印(ʲ)→ 長音マーカー(例: じょう → `죠ʲᵒᵒ`)。ん・っ のパッチムは音節に付くので、長音の後ろの ん は `혼ᵒᵒ`(ほーん)のように、パッチム付きの音節の右肩に長音を書く。
2. **詳細版は 長音・促音・区切り `·`・じゃ/じょ の `ʲ` の全部を書く。**
3. **ライト版は 長音・促音・区切り `·` を書き、じゃ・じょ の `ʲ` だけ落とす。** ざ/じゃ、ぞ/じょ は同じ綴りになることを許容する(常用語で 118 語・0.54%)。
4. **右肩の母音字(ᵃ ⁱ ᵘ ᵉ ᵒ)は詳細・ライトの両方で使うので、フォントの用意が要る。** 同梱フォントにあるのは `ʲ` だけで、ᵃ ⁱ ᵘ ᵉ ᵒ は kana-c・kana-support・kana-multi のどれにも無い(2026-09-29 に cmap を確認)。`kana-support` 系に足す(ADR-0014)。字形 (a)/(c) の最終決定は `tools/glyph-check/public/hangul.html` を実機で見てから行う(ADR-0004)。

## 検討した代替案
- **長音を母音の重ね書き(오바아산)、じゃ/じょ を下付き結合記号(U+0324)にする(初案)**: 標準ハングルで書ける利点があったが、クメール側の方針(右肩ローマ字)と揃わないため、ユーザー判断で取り下げた。
- **ライトにも `ʲ` を残す**: 衝突は 0.54% から 0.13% 未満になる。ʲ は既存フォントにあるが、ADR-0006 の基準(0.5% 以下は落とす)とほぼ同じ水準で、ライトの記号を増やすほどではない。
- **区切りをライトで落とす**: ADR-0018 でユーザーが却下(ん+ら行の誤読が残る)。
- **長音を詳細だけにする**: 衝突 13.5% を許容することになるので却下。長音はライトの中核。
- **促音を詳細だけにする**: 衝突 3.1%。同位置パッチムは標準文字で書けて費用がほぼ無いので、ライトに残す。

## 結果(影響)
- ライトと詳細の違いは じゃ・じょ の `ʲ` だけになる。長音と右肩のフォント依存は両方に残る。
- 右肩の母音字のグリフを足すまで、長音は多くの端末で欠字になりうる(同梱フォントに無いため)。
- ライトで ざ/じゃ・ぞ/じょ が同じ綴りになる(例: 座/蛇、象/錠)。学習用途では詳細版で補える。
- 右肩の文字はハングルの分かち書きや行分割を乱しうるので、音節+右肩は `white-space: nowrap` で包む(khmer 側 ADR-0010 決定3 と同じ)。未検証。
- 数値は暫定の表・韓国語の読み規則の近似(`pronounce`)による。ネイティブ確認で表が変われば測り直す。語彙は JMdict 常用語で、字幕のような自由文での頻度は未測定。
