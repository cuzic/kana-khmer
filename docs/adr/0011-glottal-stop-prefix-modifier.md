# ADR-0011: 子音連続先頭の ʔ は `◌̯` グループに入れず、専用の modifier `ˀ` を次のカナの直前に置く

## コンテキスト
子音連続の先頭に `ʔ` が立つケース(`អ្វី` の口語形 `ʔʋəj`)が実データで必要になった。既存の
「母音なしの子音」グループ(`◌̯` 付き通常カナ。例: c は `チ̯`)に倣うなら、`ʔ` にも母音を持つ通常カナ
(イ段の `イ̯` 等)を当てる案があったが、`ʔ` はこの位置ではほぼ無音のため、母音を持つカナを当てると
存在しない母音があるように読めてしまう。

## 決定
`ʔ` は [ADR-0005](0005-ng-shared-modifier.md) の `ᵑ` と同じ「独立した modifier」方式で、
`ˀ`(U+02C0)を採用する。ただし配置規則は `ᵑ`(音の右肩)とは異なり、**次に来る主子音のカナの直前**に
置く(`cons-mod` span だが、位置が右肩の `ʰ ˡ ʳ ᵑ` と違い、後ろの音の手前に来る)。`ʔ` はこの並びでしか
prefix 役にならない(主オンセットや単独オンセットのときは母音行の通常カナになる)ため、位置は常に
「次の音の手前」の1箇所に固定される。

## 検討した代替案
- **`◌̯` 付きの通常カナ(イ段の `イ̯` 等)で書く**: 存在しない母音があるように読めるため却下。

## 結果(影響)
子音連続先頭の未定義文字(`ɓ ɗ n ɲ ŋ h r j ʋ`)は引き続き `NO_VOWELLESS_FORM` エラーとし、実データで
必要になった子音だけをネイティブ確認後に個別に決める方針を維持する。`ˀ` はライト表記では
[ADR-0006](0006-lite-drop-by-functional-load.md) の「落とす集合」に入っており、ライトでは消える
(この位置ではほぼ無音のため)。ネイティブ確認は未実施のまま。
