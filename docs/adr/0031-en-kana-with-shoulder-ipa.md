# ADR-0031: 英語の実際の音は、日本語話者が読める基本のカナ + 右肩の IPA 小文字で表記する

## コンテキスト
英語字幕に「実際の音」を重ねる際([ADR-0030](0030-en-subtitle-prosody-ir-and-selectable-layers.md))、カナだけでは日本語にない区別が消える
(L/R、th、`æ` と `ʌ` など)。IPA だけでは日本語話者の初学者に読めない。このリポジトリは、khmer-kana・ko-kana で
「基本のカナ + 右肩の修飾文字(IPA の小文字)」を使っている([ADR-0005](0005-ng-shared-modifier.md)・[ADR-0024](0024-ko-kana-notation.md))。

IPA の字のうち、Unicode に右肩形(修飾文字)があるものを調べた(fontTools でなく Unicode 名で確認)。`ɚ` `ɝ` `ɾ`(弾き音)を除き、英語の音に要る字はすべて持っている
(`ʳ ˡ ʰ ᶿ ᶞ ᵆ ᶺ ᶦ ᶷ ᵓ ᵊ ᵑ ᵈ ᵇ ᵍ ᶻ ᶾ ᵛ ᵗ`)。

## 決定
**基本のカナは日本語話者が読める最も近い音にし、日本語にない区別を IPA の小文字で右肩に添える。** 実装は `tools/en-prosody-spike/src/kana.py`(挙動の正)と
`packages/en-prosody/src/kana.ts`(TS 版)。表記の文字列に NFKC/NFKD を適用しない(修飾文字が通常の文字に置き換わる)。

| 音 | 表記 | 例 |
|---|---|---|
| r / l | ラ行 + `ʳ` / `ˡ` | right = ラʳイㇳ、light = ラˡイㇳ |
| θ / ð | サ行・ザ行 + `ᶿ` / `ᶞ`(i の前は シᶿ / ジᶞ) | think = シᶿᶦンᵑㇰ、this = ジᶞᶦㇲ |
| v | ヴ行(慣用) | very = ヴェリʳー |
| æ / ʌ / ɪ / ʊ / ɔ | ア + `ᵆ` / ア + `ᶺ` / イ + `ᶦ` / ウ + `ᶷ` / オ + `ᵓ` | cat = カᵆㇳ、cup = カᶺㇷ゚ |
| ə(弱い母音) | 子音の小書きカナ + `ᵊ` | about = ァᵊバウㇳ |
| ɚ(弱い r 色の母音) | 子音の ア 段 + `ʳ`(ᵊ は付けない) | never = ネヴァʳ、dinner = ディᶦナʳ |
| 弾き音 | ラ行 + 元の音の字(`ᵗ` `ᵈ`) | what I = ワᶺ ラᵗイ |
| ts / dz | ツ / ヅ(語末でも母音の前でも) | it's = イᶦツ、kids = キᶦヅ |
| dʒ / ʒ / tʃ | ヂ行 / ジ + `ᶾ` / チ行(語末は チ) | strange = ㇲㇳレʳインヂ |
| 子音 + y + 母音 | 子音の i 段 + 小書き ャュョ | future = フューチャʳ、music = ミューズィᶦㇰ |
| ʃ・tʃ・dʒ・ʒ + 弱い母音 | 語末は シャ・チャ・ヂャ・ジャᶾ、音節を成す n の前は シᵊン・チᵊン・ヂᵊン、語末でない dʒ は デュ | nation = ネイシᵊン、education = エデュケイシᵊン |
| 母音の前以外の子音 | 母音を足さない小書きカナ(ㇰ ㇳ ㇷ゚ ㇲ ㇱ ㇺ ㇽ)+ 有声の右肩(`ᵈ` `ᵍ` `ᵇ` `ᶻ`) | strange の `ㇲㇳ` |
| ŋ | ン + `ᵑ` | think の `ンᵑ` |

- `ɚ` を `ᵊʳ` でなく `ʳ` だけにしたのは、幅を減らすため(ユーザー判断)。
- 「詳細」は右肩の IPA を含め、「ライト」は右肩を除く([ADR-0002](0002-two-level-notation-via-spans.md) の考え方と同じ)。
- 各記法の右肩の字は、その記法の中で意味を持つ。ko-kana の `ᵓ`(ㅓ)と本記法の `ᵓ`(ɔ)は、字が同じで意味が違う。

## 検討した代替案
- **カナだけ**: L/R・th・母音の区別が消える(ko-kana の設計でも、記号を落とした素のルビは衝突が多かった)。
- **IPA だけ**: 日本語話者の初学者には読めない。
- **IPA にない独自の修飾記号を作る**: 読み取れる根拠がなく、フォントにも無い。IPA の字そのものを右肩に置く方式にした(ユーザーの指示でもある)。
- **`ts` `dz` を小書きカナ 2 字(`ㇳㇲ` `ㇳᵈㇲᶻ`)で書く**: 読めない。破擦音は 1 字のツ・ヅで書く。
- **`dʒ` をジ行で書く**: ʒ(ジ行 + `ᶾ`)と書き分けられない。ヂ行にした(ユーザー指定)。
- **弱い `ə` も全角のカナ(ハプン・セカンド)にする**: 読みやすいが幅が広がる。小書き + `ᵊ` のままにした(ユーザー判断)。
- **子音が並ぶ語頭の小書きカナ(`ㇲㇳ`)を全角(ストレ)にする**: 幅を減らすため小書きのままにした(ユーザー判断)。

## 結果(影響)
- **実機(iOS/Android)での描画は未確認。** `tools/glyph-check/public/en-prosody.html` と CI の配線(`.github/workflows/glyph-check.yml`)は作ったが、CI は未実行
  (GitHub Actions の利用枠を使うため、push の判断をユーザーに仰いでいる)。手元の Linux の Chrome では欠字・位置崩れは見えなかった。
  Noto Sans JP は 19 の修飾文字をすべて欠き、DejaVu Sans・Noto Sans(latin-ext)は持つ(fontTools の cmap で確認)。欠字があれば、
  [ADR-0003](0003-composite-combining-glyph-font.md)・[ADR-0014](0014-three-font-split.md) と同じ要領でフォントを同梱する必要が出る。
- 右肩の文字が 2 つ重なる語(`シᶿᶦンᵑㇰ`)は、実機で読めるか未確認。
- 規則を直すたびに別の語の表記が変わり得る。突き合わせテスト(60 文)が守るのは、TS 版と Python 版の一致であり、表記が正しいかではない。
  表記の正しさは、ユーザーが個々の語を見て判断している(目視が正: [ADR-0004](0004-visual-review-is-authoritative.md))。
- `you're` は弱形で `ヤʳ` になる(ɚ の規則の副作用)。意図どおりかは未確認。
- Python の `ROWS` に `dz` の行が無く、`dz` の直後に母音が来る語で例外になる不具合があった(2026-09-30 に修正)。
