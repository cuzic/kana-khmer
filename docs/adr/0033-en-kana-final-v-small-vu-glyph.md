# ADR-0033: 英語の語末の有声子音は、無声の小書きカナ + 濁点を、小書きの ド ブ グ ズ ジ ヴ に合字して書く

## コンテキスト
[ADR-0031](0031-en-kana-with-shoulder-ipa.md) の実装は、母音の前以外の v(`love`・`of` の強形など)を `ㇷᵛ`(小書きの ㇷ + 右肩の `ᵛ`)で出していた。
ところがライトは右肩の字を一律に消す暫定なので、`love` が `ラㇷ`(= `ラフ`)になり、`luff` と区別できなかった。右肩の `ᵛ` も小さく、詳細でも `ラフ` に見えた。
語末の v は有声音で、`love`(/lʌv/)と `luff`(/lʌf/)は別の語になる。有声の語末子音は声が弱まりやすいが、母音の長さと摩擦の強さで区別される。

**ユーザーの発言(原文)**:
- 「love とかは本来 ラヴ と書くべきだと思うのですが、どうして ラフ になっているのか。」
- 「では、ラヴ であるべきですね。小文字の ヴ　とかのグリフを作成することで対応しましょう。」
- 「ㇷ゚ᵇ、ㇳᵈ、ㇰᵍ、ㇲᶻ これら、全部のグリフを作成して、対応してくださいね。」

## 決定
1. **母音の前以外の有声子音は、無声の小書きカナ + U+3099(結合用の濁点)で書く。** 同梱フォント(`kana-multi.woff2`)が、この並びを 1 つの小書きグリフに合字する(ㇷ + U+309A が ㇷ゚ になるのと同じ作り。`tools/glyph-check/scripts/build-kana-multi-font.py`)。

   | 音 | 文字列 | グリフ |
   |---|---|---|
   | g | ㇰ + U+3099 | 小書き グ |
   | ʒ(語末・子音連続) | ㇱ + U+3099 | 小書き ジ |
   | z | ㇲ + U+3099 | 小書き ズ |
   | d | ㇳ + U+3099 | 小書き ド |
   | b | ㇷ゚ + U+3099(ㇷ + U+309A + U+3099) | 小書き ブ(小書き ㇷ に濁点) |
   | v | ㇷ + U+3099 | 小書き ヴ(小書き ゥ に濁点。本物の ヴ が ウ + ゛ なので、ブ と見分けがつく) |
2. **右肩の `ᵈ` `ᵍ` `ᵇ` `ᶻ` `ᵛ` を、この用途では使わない。** `packages/en-prosody/src/kana.ts`・`tools/en-prosody-spike/src/kana.py` の語末(子音だけ)の出力を上の文字列にする。母音の前の `ᶾ`(ジ行 + `ᶾ`)と、弾き音の `ᵗ` `ᵈ`(ラ行 + `ᵗ` `ᵈ`)は変えない。
3. **ライトでも残る。** U+3099 は右肩の修飾文字の集合(`MODS`)に入っていないので、`lite()` で消えない(`love` のライトは `ラㇷ゙`)。ライトで有声の印を残すかは、これで決まる(`docs/en-kana-spec.md` §5 未決 1 の一部)。
4. **`ㇱᶾ`(ʒ の語末)も同じ方式にする。** ユーザーの列挙には無かったが、同じ仕組みで、ジの小書きがないと ʃ と ʒ が区別できなくなるため(agent の判断)。

## 検討した代替案
- **`ㇷᵛ` のまま、ライトで `ᵛ` だけ残す**: 右肩の字が小さく、読み落としやすい。
- **有声の印を右肩の `ᵈ` `ᵍ` `ᵇ` `ᶻ` `ᵛ` のままにする**: 小さくて読み落としやすく、ライトで一律に消えると `love`/`luff`、`bed`/`bet` が同じになる。
- **全角の `ヴ`**: ウ段の母音(ゥ)が付いて読まれ、幅も広がる。母音の前以外の子音を小書きで書く原則(ADR-0031 §2)に反する。
- **合字せず ㇷ + U+3099 のまま**: 合字のないフォントで ㇷ に濁点が浮く。ただし意味は残る。いまの設計はこの縮退を許容している(ㇷ゚ と同じ)。
- **専用の私用領域(PUA)の 1 コードポイントにする**: フォントがない環境で文字が消える。2 字の合字にすれば、フォントがなくても ㇷ + ゙ として読める。

## 結果(影響)
- 同梱フォントの再生成と、`en-prosody.html` での描画確認(目視)が必要。**目視は未実施。**
- `packages/en-prosody/test/golden.json` の v の語(`love`・`of` など)が `ㇷ゙` になる。Python 版と TS 版の一致は `parity.test.ts` が守る。
- ブラウザ拡張はフォントをまだ同梱していない(ADR-0031 の結果を参照)。同梱するときに、この合字も入る。
- `ㇷ゚` + U+3099(ブ)と `ㇷ` + U+3099(ヴ)は、文字列では「無声 + 濁点」の同じ規則で、字形だけが違う。フォントのない環境では、どちらも小書きに濁点が付いた並びとして読める。
