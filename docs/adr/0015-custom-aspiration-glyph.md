# ADR-0015: 有気音マーカー `ʰ` の字形を Noto 標準の小さい "h" からカスタム字形(点+テール)に変更する

## コンテキスト
`ʰ`(U+02B0、有気音マーカー)は Noto 標準では小さい "h" の字形で描かれる。これだと、カナ表記に
慣れていない日本語話者が「h の音を足す」記号だと誤読するおそれがある(実際に有気音は無気音+
息の強さの違いで、ローマ字の "h" が持つ音価とは別物)。

## 決定
`ʰ` の字形を、丸い頭が右肩・左下に尖った尾を持つ「点+テール」のカスタム字形に変更する
(`tools/glyph-check/scripts/build-kana-support-font.py`、`kana-support.woff2` のみの変更)。
コードポイント(U+02B0)・表記上の位置(右肩、`ʳˡᵑ` と同じ `cons-mod` 枠)は変更しない。

## 検討した代替案
- **二重アポストロフィーなど別の記号を当てる**: 濁点(2本線)に見た目が寄ってしまい、
  「有声化の印」と紛れるおそれがあるため避けた。

## 結果(影響)
将来、有声有気音(ヒンディー語等の breathy voice、IPA では `ʱ`)をカナ表記に足す場合、濁点行(ガ)に
この「点+テール」をそのまま足す案が有力になる(カ側に別記号を足す案は、濁点との混同という同じ問題を
再発させるため避ける)。有声/無声はガ/カの行で既に区別できているため、点+テール自体はカ用・ガ用で
使い回せる(IPA が `ʰ`/`ʱ` を分けているのは、ラテン文字側に行の区別が無いから)。ネイティブ・実機での
確認は未実施。
