# ADR-0013: `◌̯`(U+032F)で「母音なしの子音」を表し、ライトでも残す

## コンテキスト
クメール語の子音連続(例: `cʰkae`)の先頭に来る、母音を伴わない子音をどう書くかが課題だった。
何も印を付けずに子音単独のカナ(例: `チ`)を書くと、日本語話者は「チ」に母音(i)を補って読んでしまう
(`cʰkae → チカエ` と書くと「チカエ」の4拍に読まれる)。IPA の U+032F は本来「非音節化」(母音の
非音節化)を表す記号で、「母音なしの子音」を表す用法は IPA の原義とは異なる転用である。

Opus レビューで「ライト表記では `◌̯` も含めて修飾文字をすべて落とすべきでは」という指摘(H2)を
受けたが、`◌̯` を落とすと上記の誤読が再発する。

## 決定
基底のカナに結合文字 `◌̯` を付けて「母音なしの子音」を表す(例: `チ̯`)。**ライト表記でも `◌̯` は
落とさない**(削除対象の修飾文字の数を1つ減らす)。IPA の原義とは意味が違う転用であることは、
説明文で1行断る。

## 検討した代替案
- **無印の子音カナで書く**: 日本語話者が母音を補って読んでしまうため却下。
- **ライトでも一律に修飾文字を落とす(`◌̯` も含む)**: 「母音を足さない」という表記の中心的な約束が
  崩れ、`cʰkae → チカエ` のような誤読が再発するため却下。

## 結果(影響)
`◌̯` は表記の中で唯一「常にライトでも残る」結合文字となり、[ADR-0003](0003-composite-combining-glyph-font.md)
の合成フォント(基底+結合文字を1つのフォントに同梱)が必要になった直接の理由でもある。`◌̯` が付く
基底文字が増えるたびに、そのフォントにその基底を追加するコストが発生する(現状は c(チ)のみ)。
