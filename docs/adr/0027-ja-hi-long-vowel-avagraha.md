# ADR-0027: ja-hi の長音は avagraha `ऽ` を直前の拍の直後に足して書く

## コンテキスト
ja-khmer は長音を、直前の母音の上付きローマ字+結合マクロン(ᵃ̄ ⁱ̄ ᵘ̄ ᵉ̄ ᵒ̄)の右肩記号で書く([ja-khmer-spec.md](../ja-khmer-spec.md) §3.2・D9)。結合文字なのでフォント依存で、ADR-0003・ADR-0014 の合成グリフが要る。
[ja-hi-spec.md](../ja-hi-spec.md) v0.1 は、当初これを流用する案だった(ADR-0025 の枠組み)。

ヒンディー語版 Wikipedia・Wiktionary の日本語由来の記事名で、長音がどう書かれているかを調べた
([research/2026-09-29-ja-loanwords-in-brahmic-wikipedia.md](../research/2026-09-29-ja-loanwords-in-brahmic-wikipedia.md) の「長音の書き方」。語数は少なく目視):

- ō・ē は短い拍と同じ `ो े` で、**長さが文字に出ない**(कोबे・क्योटो・टोक्यो 等)。ā も `ा` のまま。
- ū・ī は `ू ी` が多いが、長い ū を短い `ु` で書く語(चुबू・फ़ुजित्सु)も、短い u を長い `ू` で書く語(सूशी・सूमो)も多く、**揺れる**。
- **avagraha `ऽ`(U+093D)を長さの印に使う例が1つある**(ヒンディー語版 Wikipedia の `ओऽनो`(大野 Ōno))。標準の慣習ではない。`ऽ` は本来サンスクリットで語頭の a の脱落を表す記号で、ヒンディー語では呼びかけや詩で母音を引き伸ばす印にも使われる(一般知識、文献未照合)。

長さを書き分ける既存の慣習が無いので、印を追加する必要がある。

## 決定
1. **長音「ー」は、直前の拍の直後に `ऽ`(U+093D)を1つ足して書く。全母音に付ける。** 例: とう → `तोऽ`、きー → `किऽ`、くう → `कुऽ`、ああ → `ाऽ`(語頭では `अऽ`)。
2. **基底の母音記号は短い形のまま**(i・u も `ी ू` に替えない)。ヒンディー語話者は `ी ू` を長い音と読むので、長さの印は `ऽ` だけにして、規則を全母音で同じにする。
3. **右肩記号・結合文字・合成グリフは使わない**。`ऽ` は通常のデーヴァナーガリーの文字なので、ja-hi では ADR-0003・ADR-0014 のフォント作業が要らない。
4. ん・っ が続くときは、`ऽ` を ん・っ より前に置く(カーン → `काऽन्`。拍の時間順)。詳細とライトの両方に残す。

## 検討した代替案
- **ja-khmer と同じ右肩ローマ字+結合マクロン(ᵃ̄ 等)**: ja-khmer と記号をそろえ、フォントの合成グリフを流用できる。しかし結合文字で、Devanagari の基底の右での位置・古い Android での欠字(ADR-0003 の実測は ◌̯)が未確認。ユーザーが `ऽ` を選んだ。
- **基底を長母音記号にする(ी ू)+マーカー**: i・u で長さを二重に示し、規則が あ・え・お と食い違う。ヒンディー語の慣習では ी ू も長短が揺れるので、長さの手がかりとして頼れない。却下(決定2)。
- **独立母音字の重ね書き(तोओ 型)**: ベンガル語版 Wikipedia の地域・県の記事に例がある(তোও・চুউ)。ヒンディー語には例が無く、独立母音字の直前の結合が不自然になる。ja-bn の候補としては残す(ja-bn の設計書で決める)。
- **`ː`(U+02D0)などの IPA の長音記号**: デーヴァナーガリーのフォントに無いことが多く、フォールバックで字形が揺れる。却下。
- **何も書かない(既存の慣習どおり)**: ō・ē の長短が消え、ja-khmer の測定(長音を潰すと衝突が増える。共通語で 11.0%)と同じ問題が起きる。却下。

## 結果(影響)
- ja-hi の詳細とライトの差は無い(記号が `ऽ` だけで、右肩記号が無い)。
- **未確認**: (1) `ऽ` の描画(Noto Sans Devanagari、古い Android WebView、iOS。`tools/glyph-check` の範囲)。(2) **ヒンディー語話者が `ऽ` を長音の印として読むか**。呼びかけや詩の引き伸ばしと読まれる可能性が高いが、話者の確認が要る。
  (3) `ऽ` の後に結合字が続くとき(例: `तोऽक्योऽ`)の見た目。
- ja-bn(ベンガル語)には当てはまらない。ベンガル文字にも avagraha `ঽ`(U+09BD)があるが、ベンガル語での長音の印としての用法は未調査で、ja-bn の設計書で決める(重ね書きの前例がある)。
- ja-hi と ja-khmer で長音の印が違う(`ऽ` と右肩マクロン)。字幕表示など両言語を並べる画面では、言語ごとに読み方が違うことを前提にする。
