# ADR-0018: 日本語→ハングル表記で、ん・っ の直後が母音・ら行のとき区切り記号を入れる

## コンテキスト
日本語→クメール文字(ADR-0010・ADR-0017)に続き、日本語→ハングルの表記を検討している
(`tools/ja-hangul-spike/`。使い捨てのスパイク、表は韓国語ネイティブ確認前の暫定)。
ハングルは音節末(パッチム)に ㄴ ㅇ ㅁ が置けるので、撥音「ん」と促音「っ」は書ける。
ところが韓国語話者は綴りを**韓国語の読み規則**で読むため、パッチムの直後の音節で発音が変わる。

- **連音化**: パッチム + 母音始まり(ㅇ)の音節 → パッチムが次の音節の頭に移る。
  `혼야`(ほんや)は [호냐] と読まれ、`호냐`(ほにゃ)と同音になる。
- **流音化**: ㄴ + ㄹ → ㄹㄹ。`혼라이`(ほんらい)は [홀라이] と読まれる。
- **鼻音化**: ㅇ・ㅁ + ㄹ → ㄹ が ㄴ になる(`종로` [종노]、`심리` [심니])。

母音始まりの音節は、ア行・ヤ行・ワ(ㅇ + 母音)。「ん」の直後がこれらの語は JMdict 常用語で 230 語、
ら行の語は 187 語(全 JMdict では 4,401 語・3,397 語)。

一般にはどうしているか(調べた範囲):
- **韓国の国立国語院「외래어 표기법」日本語**: ン は常に `ㄴ`、促音は常に `ㅅ`。長音は表記しない。
  連音化・流音化への言及は、確認できた文面には無い(例: サッポロ→삿포로)。読みの崩れは放置されている。
- **北朝鮮の表記法**(二次資料による): 母音の前と語末は `ㅇ`、それ以外は `ㄴ`(信越→싱에쯔)。
  母音の前を ㅇ にするのは連音化を避ける意図とみられるが、それでも ㅇ+ㄹ の鼻音化は起きる。
- **1948 年の旧規定**(二次資料による): ア・ヤ・ワ・カ・ガ・ハ行の前は `ㅇ`、サ・ザ・タ・ダ・ナ・ラ行の前は
  `ㄴ`、マ・バ・パ行の前は `ㅁ`。ラ行の前の `ㄴ` は流音化する。
- ん+ら行の誤読を、日本語の表記論として扱った資料は見つけられなかった。**既存の慣行では未解決**。

## 決定
1. **「ん」「っ」のパッチムの直後の音節が、母音始まり(ア行・ヤ行・ワ)またはら行のときは、区切り記号
   `·`(U+00B7)を間に入れる。** 例: ほんや → `혼·야`、ほんらい → `혼·라이`、ほにゃ → `호냐`。
   区切りは ん の直後だけでなく、っ の直後の母音始まり(実際にはほぼ現れない)にも同じ規則で入れる。
2. **パッチムの種類は ㄴ(ん)・同位置(っ)のまま変えない。** ㅇ や ㅁ には変えない。
3. 区切り記号は綴りの上だけの印で、発音には現れない。表示のための記号として扱い、ライト版で残すかは
   **未決**とする(下記「結果」)。

## 検討した代替案
- **ん を常に ㄴ にして区切りなし(公式の外来語表記法)**: 連音化で ほんや/ほにゃ が同音になり(常用語で
  28 語・0.13%)、ん+ら行は 187 語が [ㄹㄹ] と読まれる。ADR-0010 の「対立するものだけ印を付ける」に
  照らすと衝突は許容範囲だが、ら行の誤読は衝突ではなく音の崩れなので、許容の根拠にならない。
- **ら行の前だけ ん を ㅇ にする(初案。ユーザーへの選択肢として提示した)**: ㅇ+ㄹ は鼻音化して
  ら が な になる(ほんらい → `홍라이` [홍나이])。**流音化を避けられても別の誤読になるので却下**。
  当初の説明「ㅇ+ㄹ は流音化しない」は、鼻音化を見落としていた(2026-09-29 に訂正)。
- **ん を母音の前と語末だけ ㅇ にする(北朝鮮式)**: ㅇ パッチムは連音化で次の音節に移るので、
  `싱에쯔` は [시넹…] のように読み手側で崩れうる。ら行の前は ㄴ のままで流音化が残る。
  母音・ら行のどちらの問題も解けないので却下。
- **区切りなしで、次の音節の頭にパッチムを移した綴りにする**: ほんや → `호냐` は ほにゃ と同じ綴りに
  なり、衝突が増えるだけなので却下。
- **ハングルの外の記号(`'` や `ㆍ`)を区切りにする**: U+00B7 は Latin-1 にあり、実質どのフォントにも
  あるため glyph-check の対象外にできる。アポストロフィはローマ字(Hepburn の n')の慣行に近いが、
  ハングルの字面から浮きやすい。字形の最終決定は目視(ADR-0004)。

## 結果(影響)
- 詳細版のハングルは ん・っ の直後に `·` が入り、見た目が少し騒がしくなる(該当は常用語で約 2% の語)。
- **未検証**: `·` を挟むと、韓国語話者が本当に連音化・流音化なしで読むかは、まだ確かめていない。
  読み規則からの推定であり、ネイティブ確認が要る。
- **未決**: ライト版で区切りを残すか。ん+ら行(誤読)・ん+母音(誤読と 0.13% の衝突)は、どちらも
  区切りを落とすと読みが崩れる。長音・促音・ざ/じゃ の扱いと合わせて、詳細/ライトの境界を別途決める。
- スパイクの測定では、区切りを書かない場合の新たな衝突は 0.13%(28 語)、全 JMdict でも 0.10%
  (204 語)にとどまる。ら行の誤読は衝突として数えられないので、この数字だけで区切りの要否は決まらない。
- ハングルの見た目の細部(結合記号 U+0324 を じゃ・じょ に付ける案)は別の決定で、本 ADR の範囲外。
