# ADR-0026: 日本語→デーヴァナーガリー表記で、ん の直後が や行・母音のとき ん を ं(アヌスヴァーラ)で書く

## コンテキスト
[ADR-0025](0025-ja-hi-ja-bn-notation-direction.md) の ja-hi で、撥音「ん」の既定は `न्`(ヴィラーマ付きの न)にした([docs/ja-hi-spec.md](../ja-hi-spec.md) §6.1。ja-khmer の ន 固定と同じ方針)。
ところが `न्` は次の子音と結合字になるので、直後の拍によっては問題が出る。

- **ん+や行**: `न्`+`या` は `न्या` になり、**にゃ(`न्या`)と同じ綴り**になる。ヒンディー語話者は `न्या` を「にゃ」と読むので、ボンヤリ が ボニャリ と読まれる。
  JMdict の仮名表記を発音風カタカナにした語(`tools/ja-khmer-spike/src/vocab.mjs` と同じ範囲)で、ん+や行は常用語 81 語(全 JMdict 1,140 語)。
  ん+や行 と にゃ行 が同じ綴りになる組は、常用語で 2 組(カンユー/カニュー、キンユー/キニュー)、全体で 17 組。衝突は少ないが、**読みが崩れる**。
  ADR-0018 の ja-hangul の ん+ら行(連音化・流音化)と同じ種類の問題。
- **ん+母音**: `न्`+`आ` のように、ヴィラーマの直後に独立母音字が来る。結合字にならず、ヴィラーマが見える不自然な表示になる。衝突は無い。常用語 131 語(全体 2,962 語)。
- ん+わ・ら行・な行・ま行 等は `न्वा`・`न्रा`・`न्ना` のように結合字になり、問題が無い(常用語で ん+わ 18・ら行 187・な行 174 語)。
- ヒンディー語の綴り慣習では、アヌスヴァーラ(ं)は य・व・र・श・स・ह の前に使う(संयोग・संवाद・संहार。一般知識)。ヒンディー語版 Wikipedia の日本語由来の記事名でも、
  ん を ं で書く語(होंडा・निंजा・शिंजुकु・किंकाकू 等)が न्・無印の न より少し多い(調査メモ [research/2026-09-29-ja-loanwords-in-brahmic-wikipedia.md](../research/2026-09-29-ja-loanwords-in-brahmic-wikipedia.md))。

## 決定
1. **ん の直後が や行(や・ゆ・よ)または母音(あ・い・う・え・お)のとき、ん は `ं` で書く**(直前の拍の母音記号の上に付ける)。例: ほんや → `होंया`、れんあい → `रेंआइ`。
2. **それ以外の ん は `न्` 固定のまま**(ん+わ・ら行・な行・ま行 等、語末・単独を含む)。
3. **ライトでも残す**(衝突より読みの崩れを防ぐ規則で、ADR-0018 が区切りをライトで残したのと同じ理由)。

## 検討した代替案
- **B: 区切り記号 `·` を入れる(`न्·या`)**: ADR-0018(ja-hangul)と同じ記号で規則が単純。しかしデーヴァナーガリー文字に無い記号で字面から浮き、ライトでも残す必要がある。ユーザーが案 A を選んだ。
- **C: ZWNJ(U+200C)で結合字を切る**: 記号が見えない。ヴィラーマが見える形になるが、見た目の差が小さく、古い Android WebView(ADR-0016)・iOS での描画が未確認でフォント依存。
- **D: 何もしない**: 規則は増えないが、ん+や行の 81 語(常用語)が にゃ行と同じ綴りになり、読みが崩れる。
- **E: にゃ行の綴りを変える(निया)**: ん+や行の `न्या` を変えずに済むが、にゃ が に+や の2拍(niyaa)と読まれ、にゃ の音が崩れる。

## 結果(影響)
- ん の綴りが2つ(`न्` と `ं`)になり、ん を `न्` 固定にした判断([ja-hi-spec.md](../ja-hi-spec.md) §6.1)の例外が1つ増える。生成器は ん の直後の拍で分ける。
- 日本語の ん は や行・母音の前で直前の母音の鼻音化に近い(一般知識、**未確認**)ので、`ं`(鼻音化)の読みに近くなる見込み。**ヒンディー語話者が本当にそう読むかは、話者の確認が要る**。学習者が `ं` の読みを知らないと、ん が弱く聞こえる恐れがある。
- `ं` はヘッドラインの上に付く。ADR-0025 決定4(アクセント線の置き場所は未決)と関わるので、`tools/glyph-check` の確認範囲に含める。
- ja-bn(ベンガル語)には当てはまらない(ベンガル語は ং(アヌスヴァーラ)を ん に使う例が 0 で、`ন্` 固定が自然。調査メモ)。ja-bn での ん+や行の扱いは別に決める。
