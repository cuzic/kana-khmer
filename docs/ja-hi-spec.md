# ja-hi 実装仕様 (v0.1 案)

> **状態**: v0.1 案(2026-09-29。エージェントの下書き)。対応表は基本46音・濁音・半濁音・拗音を埋めたが、**ヒンディー語話者による確認は全行で未実施**、
> 借用語の綴りとの照合も §9 の範囲(Wikipedia/Wiktionary の目視)に留まる。表の各セルは**初期案**で、確定は §8 の未決事項と話者の確認による。
> [ADR-0025](adr/0025-ja-hi-ja-bn-notation-direction.md)(`proposed`)に従い、ja-khmer([ja-khmer-spec.md](ja-khmer-spec.md))と同じ枠組みで書いた。
> 音の記述はすべて一般知識で、文献照合は未実施。
> **ユーザー判断(2026-09-29)**: **長音は avagraha `ऽ`(U+093D)で書く**(全母音。基底は短い母音記号のまま。§3.2・§4。ADR-0027)。ん は न् 固定(§6.1)。t/d は**歯音を既定**にし、語ごとの例外を持つ(§7): **た行 त、だ行 द**。いったん、ヒンディー語版 Wikipedia の多数派(d はそり舌 ड)に合わせたが、
> 同日、**日本語の d の音の近さを優先して 歯音 द に戻した**(ユーザー判断。ja-hi・ja-bn・ja-mr でそろえる。§7)。短い う は ु のまま。
> **語頭の あ は अ**(ヒンディー語版 Wikipedia の多数派 अ 12 : आ 5。語中の あ は ा、母音の連続などの語頭でない独立母音は आ。§3.1・§5.2)。
> ADR-0025 は `proposed` のまま。

## 1. 目的と範囲

日本を旅行するヒンディー語話者が、日本語の音をデーヴァナーガリー文字で読めるようにする補助表記の**生成規則と対応表**を定める。
出力は発音そのものではなく、ヒンディー語の正書法(子音字+母音記号+ヴィラーマ)で日本語の音に最も近く読める綴りである。表記は音声と併用する(ADR-0010 決定4 と同じ)。

| 範囲内 | 範囲外 |
|---|---|
| 基本46音、濁音・半濁音、拗音 | 外来語音(ティ・ファ・ヴ・ウィ 等) |
| 撥音「ん」・促音「っ」・長音「ー」、連母音 | 漢字、かな綴りから発音への変換 |
| | ピッチアクセントの線(ADR-0025 決定4。ヘッドラインとの衝突が未決) |

## 2. 入力形式

ja-khmer と同じ([ja-khmer-spec.md](ja-khmer-spec.md) §2)。**発音を確定した日本語**(かな)を入力とし、長音は `ー`、促音は `ッ`、撥音は `ン`、助詞は発音どおり(は→ワ、へ→エ、を→オ)。

## 3. 表記の層

### 3.1 基底文字

デーヴァナーガリー文字。子音字・母音記号・ヴィラーマ(◌्)・結合字・ヌクタ(◌़)。**詳細とライトで同じ**。

**規則の骨子**(初期案):

1. **1拍 = 子音字+母音記号**。**あ段も必ず `ा` を付け、固有母音(अ)に頼らない**。ヒンディー語は語中・語末の固有母音を読まない(シュワー削除)ので、
   固有母音に頼ると さかな → सकना が sakna と読まれる。`ा` を付ければ सा का ना と3拍に読める。
2. **母音だけの拍**(あ・い・う・え・お)は独立母音字(आ इ उ ए ओ)。**ただし語(空白区切りの句)の先頭の あ は अ**(ヒンディー語版 Wikipedia の多数派。ユーザー判断)。語頭でない あ(母音の連続の2つ目、ん の後 等)は आ のまま。母音の連続(あい・かい 等)は、各拍を別に書く(हाइ、काइ。借用語の हाइकु・होक्काइदो と同じ)。
3. **ヌクタ付きの字は、基底字+U+093C の分解形で持つ**(§10)。

### 3.2 長音の印(avagraha ऽ)

**長音「ー」は、直前の拍の直後に avagraha `ऽ`(U+093D)を1つ足して書く**(ユーザー判断、2026-09-29。[ADR-0027](adr/0027-ja-hi-long-vowel-avagraha.md))。

| 印 | 意味 | 字 | 詳細 | ライト |
|---|---|---|---|---|
| 長音(`long`) | 長音(ー) | `ऽ`(U+093D。デーヴァナーガリー文字の1字) | 全ての長音に付ける | 残す |

- **ja-khmer と違い、右肩の上付き文字も結合文字も合成グリフも使わない**。`ऽ` は通常のデーヴァナーガリーの文字で、Noto Sans Devanagari に含まれる見込み(**フォントでの描画は未確認**。§8)。ADR-0003・ADR-0014 のフォント作業が ja-hi では要らない。
- **ヒンディー語では sh・ch・ts・f・z の右肩記号も要らない**: 基底の श च त्स फ़ ज़ が既に対立を担う(ja-khmer は ស が s と sh を分けられないので `ˢʰ` が要った)。**ja-hi に右肩記号は無い**。
- 母音を引き伸ばす印としての `ऽ` は、ヒンディー語の呼びかけや詩の慣用に沿う(一般知識、文献未照合)。ヒンディー語版 Wikipedia の日本語由来の記事名にも、`ऽ` を長さの印に使う例が1つある(`ओऽनो`(大野 Ōno))。ただし標準の慣習ではなく、**ヒンディー語話者が長音の印として読むかは確認が要る**。
- `ऽ` は NFKC/NFKD で変わらない(互換分解を持たない)が、CLAUDE.md のとおり適用しない。

### 3.3 アクセント線

ADR-0025 決定4のとおり、**未適用**。ヘッドライン(शिरोरेखा)と重なるため、実機で記法を決めてから別の ADR で扱う。

### 3.4 詳細とライト

当面は詳細=ライト(記号が長音の `ऽ` だけで、ADR-0006 の機能負担量を測る前に落とす理由が無い)。ん の区切り(§8 #3)が決まったら、ADR-0019 と同じ考え方で再検討する。

## 4. 母音

日本語の5母音を、ヒンディー語の短母音記号に次のように当てる(**初期案**)。長い拍は、**同じ母音記号のまま直後に `ऽ` を足す**(§3.2)。

| 日本語 | 母音記号(短い拍・長い拍とも) | 長い拍 | 備考 |
|---|---|---|---|
| あ [a] | `ा` | `ाऽ` | अ(シュワー [ə])は使わない(§3.1 の1) |
| い [i] | `ि` | `िऽ` | |
| う [ɯ] | `ु` | `ुऽ` | 日本語の う は唇を丸めない音で、उ/ऊ(丸める)とずれる。最も近い母音記号として採る(§8 #4) |
| え [e] | `े` | `ेऽ` | |
| お [o] | `ो` | `ोऽ` | |

- **長音は全母音に `ऽ` を付け、基底の母音記号は変えない**(ユーザー判断)。i・u も ी ू にしない: ヒンディー語話者は ी ू を長い音と読むので、長さの印が `ऽ` だけで、規則が全母音で同じになる。
  ja-khmer のように基底を長母音記号にする方式は採らない(ADR-0027)。
- **既存の綴りとの関係**(ヒンディー語版 Wikipedia・Wiktionary の記事名。[調査メモ](research/2026-09-29-ja-loanwords-in-brahmic-wikipedia.md) の「長音の書き方」): ō・ē は短い拍と同じ ो े で、長さが文字に出ない。ū・ī は ू ी が多いが、長い ū を ु で書く語も、短い u を ू で書く語も多い(揺れる)。
  したがって、長さを書き分ける既存の慣習は無い。`ऽ` は、既存の綴りの ो े ू ी と重ならない、追加の印になる。
- 例: とうきょう → `टोऽक्योऽ`(東京。定着語なので t は ट)、ありがとう → `अरिगातोऽ`、おはよう → `ओहायोऽ`、きー → `किऽ`、くう → `कुऽ`、カーン → `काऽन्`。

## 5. 対応表

### 5.1 凡例

- 表の綴りは**短い拍**。長い拍は、同じ綴りの直後に `ऽ` を足す(i・u 段も ी ू に替えない)。
- **状態**: すべて**未確認**(話者の確認なし)。「参考」の欄は、en.wiktionary の「Hindi terms derived from Japanese」カテゴリにある語(2026-09-29 に目視)のうち、
  その拍を含むものの例で、**綴りの正解ではない**(英語経由・編集者の転記を含み、ゆれがある。§9)。

## 6. 撥音・促音・長音、連母音

### 6.1 撥音「ん」

**न् 固定**(ja-khmer の ន 固定と同じ方針。後続音による同化の書き分けをしない)。**例外: ん の直後が や行・母音のときは ं**(ADR-0026、下記)。न् は次の子音と結合字になる(例: こんにちは → कोन्निचिवा)。

- 借用語の実例は割れる(目視で ं が कांजि・मांगा・सेंदाई、न・न् が होन्शू・गुन्मा・शिनकानसेन・पोकेमोन・येन)。ं(アヌスヴァーラ)固定は代替案(§8 #3)。
- **ん の直後が や行・母音のとき問題がある**(2026-09-29 に整理。数は JMdict の仮名表記を発音風カタカナにした語で、`tools/ja-khmer-spike/src/vocab.mjs` と同じ範囲):
  - **ん+や行**: न्+या = `न्या` は **にゃ(न्या)と同じ綴り**になり、ボンヤリ が ボニャリ と読まれる。常用語 81 語(全 JMdict 1,140 語)。同じ綴りになる組は、常用語で 2 組(カンユー/カニュー、キンユー/キニュー)、全体で 17 組。**衝突は少ないが、読みが崩れる**(ADR-0018 のハングルの ん+ら行と同じ種類の問題)。
  - **ん+母音**: न्+आ のように、ヴィラーマの直後に独立母音字が来て、表示が不自然になる(結合字にならず、ヴィラーマが見える)。衝突は無い(न्आ は な=ना と違う)。常用語 131 語(全体 2,962 語)。
  - **ん+わ・ら行・な行**: `न्वा`・`न्रा`・`न्ना` のように結合字になり、問題は無い(常用語で 18・187・174 語)。ん+ま行・ば行も同様(同化はしない。§6.1 の既定)。
- **区切りの案**(**決定: 案 A**。ん+や行・ん+母音だけが対象):

| 案 | 綴り(ほんや・れんあい) | 長所 | 短所 |
|---|---|---|---|
| **A: ん を ं にする** | `होंया`・`रेंआइ` | 新しい記号が要らない。**ヒンディー語の綴り慣習と同じ**(संयोग・संवाद のように、ं は य・व・र・श・स・ह の前に使う)。日本語の ん は や行・母音の前で、直前の母音の鼻音化に近く(一般知識、未確認)、ं の読みに近い。न्या との衝突が無くなり、表示も自然 | ん の綴りが2つになる(न् と ं)。「न् 固定」の例外になる。学習者が ं の読み(鼻音化)を知らないと、ん が弱く聞こえる恐れ |
| **B: `·` を入れる** | `न्·या`・`न्·आइ` | ja-hangul(ADR-0018)と同じ記号で、規則が単純。どのフォントにもある | デーヴァナーガリー文字に無い記号で、字面から浮く。ライトでも残す必要がある |
| C: ZWNJ(U+200C)を入れる | `न्‌या`(見えない) | 記号が見えない。ヴィラーマが見える形になり、न्या の結合字と区別できる | 見た目の違いが小さい。古い Android WebView(ADR-0016)・iOS での描画が未確認で、フォントに依存する |
| D: 何もしない | `न्या` | 規則が増えない | ボンヤリ が ボニャリ と読まれる。ん+や行 81 語(常用語)が崩れる |
| E: にゃ行の綴りを変える(निया) | にゃ=`निया` | ん+や の न्या を変えなくてよい | にゃ が に+や の2拍(niyaa)と読まれ、にゃ の音が崩れる。**却下候補** |

- **決定(ユーザー判断、2026-09-29): 案 A**。[ADR-0026](adr/0026-ja-hi-n-before-ya-and-vowel.md)(`proposed`)に記録した。以下は提案時の理由: **案 A**。理由: 新しい記号が要らず、ヒンディー語の綴り慣習に沿い、日本語の音にも近い。ん を न् 固定にした判断(ja-khmer の ន 固定と同じ方針)の**例外を1つだけ**持つ形になる。
  ライトにも残す(衝突より読みの崩れを防ぐためで、ADR-0018 と同じ)。**ん+わ・ら行・な行は न् のまま**。
- 案 B を採る場合は ADR-0018 と同じ表示・フォント確認(`·` の字形)、案 A を採る場合は ं の描画確認(ヘッドラインの上に付くので、アクセント線(ADR-0025 決定4)の置き場所とも関わる)を、`glyph-check` の範囲に加える。
- ADR-0018 が「ライトでも残す」を決めたのと同じ理由で、決まったら ADR にする(ADR-0026 の候補)。

### 6.2 促音「っ」

**次の子音を重ねる**(子音字+ヴィラーマ+同じ子音字。結合字)。借用語の होक्काइदो・साप्पोरो と同じ形。

| 次の子音 | 例 | 綴り |
|---|---|---|
| k | いっか | इक्का |
| t | きって | कित्ते |
| p | いっぱい | इप्पाइ |
| ch | いっち | इच्चि |
| s / sh | ざっし | ज़श्शि |

- ts の前(っ+つ)は त्त्सु のように3字の結合になる。描画とシュワー削除の影響を確認する(§8 #6)。
- 語末の っ(あっ、えっ)は実例なし。**要決定**。

### 6.3 長音「ー」

§3.2 のとおり、直前の拍の直後に `ऽ` を足す(基底は変えない)。ん・っ が続くときは、`ऽ` を ん・っ より前に置く(カーン → `काऽन्`、拍の時間順)。

### 6.4 連母音

あい・おう 等は、各拍を別に書く(हाइ など)。専用の規則は持たない。**おう・おお は ō、えい・ええ は ē**(発音基準。ja-khmer §3.2 と同じ)。

## 7. 揺れの大きい音の既定

| 音 | 初期案 | ゆれ・理由 |
|---|---|---|

## 9. 検証の方法

- **借用語の綴りは参照データであって正ではない**(ADR-0025 決定5)。en.wiktionary の「Hindi terms derived from Japanese」(93 語。地名が大半)の綴りと、
  本書の表から生成した綴りを比べ、**食い違いを一覧にして見る**。一致を合格条件にはしない(t/d、ん、長音は借用語がゆれる)。
  取り込む場合は CC BY-SA 4.0 なので、別ファイルに分けて出典を付ける(ADR-0025 決定5)。
- **ヒンディー語版 Wikipedia の綴りの集計(2026-09-29)**: hi.wikipedia の「श्रेणी:जापान」とその下のカテゴリ(深さ3まで、日本関連のもの)の記事 329 件のうち、
  英語版への言語間リンクがある 307 件の記事名を使い、英語版の記事名(マクロン付きヘボン式ローマ字)から拍を割り出して、記事名の綴りと拍を順に対応づけた
  (拍の数が一致した語だけ。同じ人物名の別記事は1回だけ数えた)。使った記事は日本の地名・人名・企業・文化語で、人名が多い。
  結果は次のとおり。件数は拍の数で、語の数ではない。
  - **t**: 歯音 त 32 : そり舌 ट 11。ट は 東京・京都・トヨタ・高松・味の素・アントニオ猪木 等。
  - **d**: そり舌 ड 13 : 歯音 द 6。द は 北海道・岸田・大輔・大 等。
  - **短い う**: ु 51 : ू 13(長い ū だが英語版の記事名にマクロンが無いもの(本州・九州・阪急・柔道)は除いた)。ू は सूशी・सूमो・शिज़ूओका・शिकोकू 等。
  - **ん(子音の前)**: ं 8 : न् 8 : ヴィラーマ無しの न 5。半々で、न् 固定(ユーザー判断)を覆す根拠にならない。
  - **長さとの関係**: 英語版の記事名の多くにマクロンが無く、長短を確かめられる拍が少ない(長い t/d は東大寺・関東の2拍だけで、どちらも歯音)。**長い拍がそり舌になる、という仮説は確認できない**。
  - **限界**: 記事名は編集者が付けた綴りで、話者の自然さの証拠ではない。英語経由で定着した語(トヨタ・ホンダ・東京)は英語の綴り慣習の影響が大きい。
    人名は英語圏の綴りに引かれる。集計は自動の対応づけで、目視で照合したのは t/d の一覧だけ(u・n は自動集計のまま)。Wikipedia の本文は CC BY-SA で、この集計は綴りの頻度だけで文を引用していない。
  **再集計(同日、対象を 402 件の英語版記事名に広げ、hi は 331 件)**: t は歯音 39 : そり舌 15、d は歯音 7 : そり舌 16、短い u は ु 56 : ू 21、ん は ं 11 : न् 8 : 無印 6。傾向は同じで、上の数字は最初の集計(307 件)のもの。
  マラーティー語・ネパール語・ベンガル語・アッサム語の同じ集計と、そこから読み取れること(hi の d のそり舌は他言語と違う、ベンガル語は長短が綴りに出ない、等)は
  [調査メモ](research/2026-09-29-ja-loanwords-in-brahmic-wikipedia.md)にある。
  集計の手順は再現できる(API で categorymembers と langlinks を取り、ヘボン式をパースして数える)が、スクリプトはリポジトリに入れていない。
- **読み戻しの検証はしない**: km-IPA のようなヒンディー語の機械読み戻しの手段は未調査。Wiktionary の `{{hi-IPA}}` が使えるかを先に調べる(§8 に追加する候補)。
- **話者の確認**が最終の検証で、表全体が対象。確認者が決まるまで、状態はすべて「未確認」。

## 10. 実装メモ

- パッケージは `packages/ja-hi`(ADR-0025 決定3)。表は本書から `pnpm gen` で生成する(`packages/ja-khmer` の `spec-parse.ts`・`spec-table.generated.ts` と同じ方式)。ADR-0023 に従い、
  ja-khmer との共通基盤は当面切り出さず、ja-hi を単独で作る。
- **ヌクタ付きの字(ज़・फ़)は分解形で持つ**: U+095B(ज़)・U+095E(फ़)は Unicode の合成除外で、NFC でも U+091C U+093C・U+092B U+093C に分解される。
  表・生成・テストとも、基底字+U+093C の並びで統一する(合成済みの字を混ぜると、文字列の比較が合わなくなる)。
- 長音の `ऽ`(U+093D)は通常の文字で、右肩記号・結合文字・合成グリフは使わない(ja-khmer と違い、ADR-0003・ADR-0014 のフォント作業が要らない)。NFKC/NFKD は CLAUDE.md のとおり適用しない。
- フォント: Noto Sans Devanagari。`ऽ` の描画と、結合字(न्नि・क्क・र्या)との並びを `tools/glyph-check` で確認する。
- ADR-0016 に従い、古い Android WebView で描画できることを `tools/glyph-check` で確認する。
