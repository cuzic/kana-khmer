# ja-thai spike(使い捨て)

発音カタカナ → タイ文字の仮変換(`src/convert.mjs`)と、Wiktionary `th-pron` による声調・母音長の読み戻し(`src/readback.mjs`)。
根拠: `docs/research/2026-09-29-ja-loanwords-in-thai-orthography.md`。実行: `node src/run.mjs`(結果は `out/report.md`、th-pron の応答は `out/thpron-cache.json` にキャッシュ)。

## 方針(POLICIES)
- A: 王立学士院 2018 年版どおり(語頭の k t p ch は有気字、語末以外の開音節は短母音も長母音で書く。i は短のまま)
- B: 開音節の短母音を短形(ะ ุ เ-ะ โ-ะ)で書く
- C: 語頭も無気字(ก ต ป จ)
- D: 語中の が行 も ก
- E: 開音節の母音を i・語末を含めすべて長母音で書く
- F: E の語末だけ短形 / G: E + 長音(ー)は母音だけの音節を足して重ねる(ユーザー判断 2026-09-29) / H: F + 重ね

## 結果(ko-ja の pron 129 語 + 官報例 58 語、755 音節。2026-09-29)
- 官報の例との一致(方針 A): 56/58。食い違い 2 件は ん 語末の ง/น の異形(官報は両方可)で、実質全件一致。
- 中声調になる音節の割合: A 63.8% / B 18.8% / C 63.8% / D 63.8% / **E 94.2%**。
- A で崩れる原因は、短い i・語末の短母音(ะ ิ ุ)が「死に音節」になって類で声調が決まること(นิ=高、จิ=低、ซุ=高、ระ=高)。
- E の残りは促音の末子音(ก ด ต ป)で終わる死に音節と、สึ(低)。
- 長短の食い違い(綴りが意図した長さと th-pron の読みが違う)は 0。
- レート制限: th-pron の API は数百回で 429 になる。複数テンプレートを 1 リクエストにまとめる(`prefetch`)。

## 追加測定(F・G・H)
- 中声調: F 76.8% / **G 94.4%** / H 78.3%(E は 94.2%)。語末を短形にすると ซุ・กะ・ตะ が崩れる(F・H)。**G は E と同じ中声調率で、長音の情報も綴りに残る**。
- F・H の「長短の食い違い 131」は、`thaiLongOf` が語末の短形を長として数えるための測定側の誤り(綴りの問題ではない)。
- G の残りの非中声調は、促音の末子音で終わる死に音節と สึ だけ。
